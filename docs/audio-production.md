# 음성·음악 제작

캐릭터 설정 작업 결과의 **나레이션·캐릭터 목소리 선택**에서 모델·목소리·언어·속도·말투를 저장한다.
내레이터도 같은 화면에서 관리한다. 최초 기본값도 먼저 저장한 뒤 **목소리 샘플 생성**을 누르고,
샘플을 끝까지 재생한 후 **샘플을 듣고 이 목소리 선택**을 누른다. 샘플 생성은 유료 API를
사용할 수 있으며 오디오 워커가 처리한다. 설정 저장만으로 생성하지 않는다.
목소리·말투·속도·모델이 바뀌면 해당 설정의 샘플을 다시 선택해야 한다. 서버는 현재 목소리와
일치하는 같은 workspace의 선택 완료 샘플을 검증하며, 듣기 여부의 최종 판단은 사용자에게 있다.
비디오 프롬프트 작업 결과의 **음성·음악 제작**에서 원본 캐릭터 작업과 답변 버전을 선택해
가져온다. ID가 같은 캐릭터에 연결하며 제목으로 자동 추정하지 않는다. 가져온 값은 독립적인
설정 스냅샷이므로 원본 목소리 설정이 바뀌어도 소급 변경되지 않는다.

새 비디오 프롬프트 답변은 `audio_plan`의 speakers/cues로 화자, 발화 원문, 전체 영상 기준
시작·종료 시간, 감정을 제안한다. 기존 답변은 수정하지 않으며 수동으로 화자·발화를 추가할 수 있다.
공통 지침은 관리자, 2D·3D·실사 연출 지침은 기존 에이전트 설정 권한을 따른다.

1. 비디오 작업에서 별도 제작을 켜고 캐릭터 작업에서 선택 완료한 목소리를 가져와 화자·발화·음원 설정을 저장한다.
2. 발화별 **음성 생성**을 누른다. 이 동작은 외부 API 비용이 발생할 수 있다.
3. 실제 음성 길이와 전사문을 확인하고 듣고 확정한다. 할당 시간 초과나 원문 불일치는 확정할 수 없다.
4. 모든 영상 클립도 확정한 뒤 **합성 미리보기 만들기**를 누른다.
5. 결과를 확인하고 최종본을 확정·다운로드한다. 이전 파일과 원본 클립은 유지한다.

새 별도 제작 모드의 영상 생성은 audio=false다. 이미 소리가 있는 영상은 원본 소리 제거에
명시적으로 동의한 뒤 합성한다. 합성은 사용 길이만큼 클립을 컷 연결하고, 음성과 배경음악을
하나의 타임라인에 배치한다. 음악의 시작 위치·시작/종료 시각·음량·반복·페이드·대사 중
음량 감소를 설정할 수 있다. 실제 영상이 계획보다 짧으면 합성을 거절한다.

배경음악 업로드는 최대 16MiB/10분이며 WAV·MP3·OGG·FLAC·M4A/MP4·AAC의 실제
디코딩을 확인한다. 음원은 workspace 내부 보관함에 저장한다. 외부 음원 검색·음악 생성,
목소리 복제, 자동 립싱크·디졸브·자막 합성은 포함하지 않는다.

## 서버 설정과 워커

`.env.example`에 `ASA_AUDIO_AI_ENABLED`, `ASA_AUDIO_API_KEY`, `ASA_AUDIO_DAILY_CALLS`,
`ASA_AUDIO_MODEL_PROFILES` 예시가 있다. 기본 생성은 꺼져 있다. API 키는 서버에만 저장하고
API/오디오 워커를 재시작한다. 기본 프로필은 OpenAI Realtime 음성 출력이다.
모델·voice 허용 목록은 서버 모델 프로필에서 관리한다. OpenAI 계정의 실제 모델 사용 권한과
한국어 발음/품질은 실제 생성으로 별도 확인해야 한다.

상단 **오디오 워커** 상태를 눌러 기존 워커 관리 모달에서 시작/작업 완료 후 중지한다.
CLI는 `./scripts/run.ps1 audio-worker`. 로컬 FFmpeg 합성에는 음성 API 키가 필요 없다.
비활성화되거나 일일 한도를 넘은 음성 대기 작업 때문에 로컬 합성까지 멈추지는 않는다.

음성 요청은 호출 전에 DB에 claim을 저장한다. 실행 중 끊긴 작업은 unknown으로 남기고
자동 재호출하지 않는다. 공급자 사용 내역을 확인한 후 화면에서 새 발화로 다시 준비한다.
합성 실패는 새 작업으로 명시적으로 재시도할 수 있다. 동일 operation ID는 재실행하지 않는다.
음성 생성 내역은 AI 사용량에 기록하지만 현재 정확한 Realtime 토큰 요율/사용량 정산은
연결하지 않았으므로 비용은 **미확인**이다. 무료 또는 0원으로 해석하지 않는다.

# 기존 작업에서 음성 검토

답변 아래 **대사별 음성 확인**에서 재생·시간표·목소리·전사를 확인하고 개별 음성을 확정한다. 선택 답변에 음성이 없으면 `base_version` 계보의 가장 가까운 음성 설정/작업을 표시하며 원본 버전을 안내한다. 기존 음성을 복제하지 않고 원본 job의 확인 상태를 갱신한다. 음성 확인은 답변 버전이나 에이전트 지침을 변경하지 않는다.

원문 불일치·설정 변경·실패 결과는 제외 영역에 보존한다. 배정 시간을 넘긴 음성은 재생할 수 있으나 확정할 수 없다. 다른 분기나 미래 버전의 음성은 자동 연결하지 않는다.

## 씬 시간 측정과 제작 음성 구분

씬의 임시 음성은 `purpose=timing`으로 시간 배분을 검증하는 용도다. 화면에서 재생 가능하지만
제작 확정과 영상 합성에는 사용할 수 없다. 샘플은 `sample`, 최종 제작 발화는 `production`이다.
목적별 생성 지문을 분리해 시간 측정 파일을 제작 결과로 재사용하지 않는다.
최종 목소리/감정을 선택한 후 실제 발화 길이를 다시 측정하고 씬 시간표를 검토해야 한다.
`after_tasks.scene_timing=true`인 씬 에이전트는 새 요청·다시 요청의 답변 저장과 함께
구조화된 `timing_plan`의 발화를 시간 측정용 음성 큐에 넣는다. 기존 답변은 소급 생성하지 않는다.
오디오 워커가 실제 음성을 생성하면 계획의 앞·사이·뒤 여백을 유지하며 순서대로 재배치한다.
본문 원문은 보존하므로 화면의 실측 시간표가 본문의 예상 시간표와 다를 수 있다.
목표 초과를 표시하며 자르거나 배속하지 않는다. 실패·불확실 호출은 자동 재시도하지 않는다.
목표 길이까지 무음을 추가하지 않는다. `timing_plan.planned_duration`은 실제 계획 끝이며
목표 `duration`과 분리한다. 명시된 계획 끝과 실측 발화를 기준으로 구성 길이를 계산하고
측정 완료 후 부족분을 표시한다. 계획 끝이 없는 이전 데이터는 마지막 배정 구간을 사용한다.
계획된 행동·반응 여백은 유지되며 그 필요성을 음성 길이만으로 검증한 것은 아니다.
대사가 없는 계획은 음성을 생성하지 않는다. 최종 제작 음성과 합성 대상에서는 제외한다.
측정용 생성에도 API 사용료가 발생한다. `ASA_AUDIO_AI_ENABLED=true` 및 실행 중인 오디오 워커가
필요하며, `ASA_AUDIO_API_KEY`가 비어 있으면 기존 `ASA_AI_API_KEY`를 사용한다.
모델/목소리는 `ASA_AUDIO_TIMING_MODEL_KEY`(기본 openai-realtime),
`ASA_AUDIO_TIMING_VOICE`(기본 marin)로 설정한다. 생성 큐는 답변 버전별로 분리된다.

측정 음성이 있는 씬 작업은 **시간 배분 확인**을 표시한다. 목표/전체 길이, 음성 실측 합계,
앞뒤·사이 여백, 화자별 타임라인과 단일 전체 플레이어를 제공하며 개별 음성 카드는 표시하지 않는다.
`timing_duration_seconds`가 없으면 마지막 배정구간 기준임을 표시한다. 중첩은 구간 합집합으로
계산하고 누락/겹침이 있는 경우 전체 재생을 차단한다. 목표 초과는 표시하며 음성을 잘라내지 않는다.
인증된 timing-preview 조회는 기존24kHz mono PCM 음성을 시간표 위치에 배치하고 나머지를 무음으로
채운다. 외부 API 호출·음성 재생성·원본 수정 없이 로컬에서 조합한다. 최대3600초다.
