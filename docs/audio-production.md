# 음성·음악 제작

## 음성 제작 에이전트

작업 공간에서 **음성 제작 에이전트**를 선택하고 발화 시간표가 저장된 씬 구성의 답변 버전을 불러온다.
편집 요청의 **대사·내레이션 만들기**로도 열 수 있다. 새 음성 작업에는 원래 화자·대사·시간을
복사한다. 작품 원문이나 시간 측정 음성은 바뀌지 않으며, 이전 씬 답변에 발화 시간표가 없으면
선택 목록에 나타나지 않는다.

화자마다 모델·기본 음색을 고르고 맞춤 샘플을 듣고 선택한다. 대사마다 감정·배정 시간과 실측 길이를
확인하고, 필요한 줄만 생성·재생·확정한다. 같은 줄의 새 시도와 기존 확정 음성은 별도 기록이다.
공급자 결과가 불확실한 시도는 자동 재요청하지 않는다. 작업 준비·설정 저장·확정은 생성 요청을
보내지 않는다. 확정한 제작용 WAV는 다운로드하거나 **영상 편집·합성 → 음원 추가**에서 선택한다.
목소리 샘플과 시간 측정 음성은 편집에 사용할 수 없다.

### 영상 타이밍 검토 기준

씬 시간표는 초안으로 사용한다. 실제 영상이 함께 검토되는 경우 컷, 시선·표정·동작의 변화,
입을 여닫는 구간을 기준으로 각 소리의 위치를 확인한다. 반응을 일으키는 효과음은 반응 직전에,
동작에서 나는 소리는 그 동작에 맞춘다. 화면 속 대사는 발화 동작에, 화면 밖 내레이션은 장면의
전달 시점과 대사 사이 여백에 맞춘다. 주변음은 의도한 장소가 이어지도록 배치하고, 배경음악은
장면 전환과 분위기 변화에 맞추되 발화가 묻히지 않게 한다. 영상에 이미 들어간 효과음은 중복 여부를 확인한다.

앞 컷의 마지막 자세·표정·시선이 다음 컷 첫 장면과 맞지 않으면 클립과 시점을 남겨 영상 계획·편집에서
확인한다. 실제 영상이나 분리 음원 없이 판단할 수 없는 항목은 미확인으로 표시한다.
독립 음성 제작의 발화 아래 **영상 타이밍 참고**에서 원문이 일치하는 생성 영상의 AI 검수 결과를
선택한다. 영상 검수는 생성 당시 저장된 발화와 프레임 표본을 비교해 발화 위치와 연기를 제안한다.
클립 시작 위치는 생성 당시 계획을 기준으로 채우며, 편집 순서를 변경했다면 조정한다.
선택한 시간과 연출은 검토 후 설정을 저장해야 적용된다. OpenAI Realtime은 발화 연출을 별도
지시로 받으며 Typecast는 현재 시간 설정을 사용한다. 화자와 발화 원문은 씬 구성의 값을 유지한다.

제작 음성을 생성한 뒤 실측 길이가 표본 구간에 들어오는지 확인하고, **제작 음성과 함께 재생**으로
직접 확인한다. 비교 중에는 참고 영상의 원래 소리를 잠시 끈다. 프레임 표본의 제안과 미리듣기가
자동 립싱크를 보장하지는 않는다. 검수 이력과 저장된 원본 영상·음성은 유지한다.

기존 음성을 조정할 때는 전체 WAV 길이와 발화 신호의 시작·끝을 따로 기록한다. 뒤 무음만
초과하면 발화가 끝난 뒤의 여백만 줄이고, 영상에서 의미 있는 쉼과 호흡은 유지한다.
등장에 맞추는 내레이션은 실루엣 첫 노출과 얼굴·정체가 확인되는 시점을 구분하고, 대사는
입이 열리는 시점과 닫히는 쉼을 기준으로 전후 발화의 겹침과 컷 끝을 확인한다.
같은 음성의 검토용 복사본에서 위치와 무음 길이를 먼저 조정한다. 사용자가 타이밍 보정을
요청했고 그것만으로 맞지 않을 때는 필요한 구간만 최소한으로 길이를 조정하고 음높이를 유지한다.
조정 전후 길이와 판단 근거를 기록하고 원본과 자르지 않은 발화를 보존한다.

동시 재생으로 검수할 때는 영상의 실제 재생 위치가 지정 시점에 도달했고 제작 음성이 같은
시점에 출력됐는지 먼저 확인한다. 재생 위치가 초기화되거나 중간에 멈추면 그 시도를 검증 근거에서
제외한다. 영상과 음성의 재생 시점이 확인되어도, 청취하지 못한 말투의 자연스러움은 미확인으로 둔다.
청취 검수에서 인용한 대사가 원문·저장 전사와 다르면 해당 발음이나 말끝 판정의 신뢰도를
낮춰 표시한다. 청취 모델의 인용만으로 기존 대사를 수정하거나 음성을 재생성하지 않는다.
한 줄 재검수는 해당 음성과 원문을 좁혀 사용한다. 음성 수신을 확인했더라도 모델이 원문을
근거로만 답하거나 청취 판단을 유보하면 말투 판정을 유보한다. 파형·재생 위치에서 확인한
절단 여부는 발음과 말끝의 청취 판정과 구분해 기록한다. 끊김이 확인되지 않은 기존 음성은 유지한다.

영상 검수에서는 실루엣의 첫 노출과 얼굴이나 정체가 확인되는 시점을 나눠 기록한다. 입이
열리고 닫히는 프레임과 중요한 반응·쉼을 표시하고, 앞뒤 발화가 겹치거나 컷 끝을 넘길 수 있는
시간 배치를 알려준다. 프레임만 관측한 경우 실제 음성의 시작·끝과 입 모양의 일치는 미확인이다.

### 선택형 Typecast 연결

기존 오디오 워커를 사용한다. 서버의 `ASA_AUDIO_MODEL_PROFILES`에 `provider: "typecast"`,
`model: "ssfm-v30"`, 표시 이름과 해당 모델에 실제로 등록된 `voices` ID를 가진 프로필을 추가한다.
`ASA_AUDIO_TYPECAST_API_KEY`, `ASA_AUDIO_TRANSCRIPTION_MODEL=gpt-transcribe` 및 OpenAI 음성 키
(`ASA_AUDIO_API_KEY`, 비어 있으면 `ASA_AI_API_KEY`)가 필요하다. 기존 OpenAI 프로필도 유지할 수 있다.
API와 오디오 워커에 같은 서버 설정을 적용한다.

Typecast는 선택한 음색과 말하기 속도로 생성한다. 직접 쓴 말투·발화 감정은 이 연결 경로에서
전송하지 않는다. 생성한 WAV를 OpenAI 전사에 보내 대사 원문과 비교하며, 전사를 확인하지 못하거나
원문과 다르면 확정을 막는다. Typecast 작업당 합성과 전사 두 건을 호출 한도에 반영한다.

공식 참고: [Typecast 합성 API](https://typecast.ai/docs/api-reference/text-to-speech/text-to-speech),
[OpenAI 전사 API](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create/).

## 현재 기본 흐름: 목소리 특징 → 영상 생성

캐릭터 상세에서는 목소리의 나이 느낌·음역·음색·말투·언어·속도 의도를 저장한다.
공통 나레이션은 상단에서 한 번 설정하며 저장 후 접힌다. 이 흐름은 별도 TTS 샘플을 생성하지 않는다.
**나레이션 목소리 직접 설정**을 끄면 입력란을 숨기고 자동 설정 안내를 표시한다.
대본의 나레이션은 유지하며 이야기 내용·장면 분위기·제공된 이미지에 맞는 목소리를 정하도록 전달한다.
꺼진 동안 기존 특징·언어·속도 입력은 새 요청에 적용하지 않고 보관하며 다시 켜면 복원한다.
새 요청 snapshot에서만 이 의미를 적용하므로 과거 답변·생성 요청의 나레이션 제외 기록은 바꾸지 않는다.
캐릭터 상세에도 **캐릭터 이름 + 목소리 직접 설정** 스위치를 제공한다. 캐릭터마다 독립적으로
선택하며, 끄면 대사는 유지하고 캐릭터 설정·이야기·장면·이미지에 맞는 자동 목소리 지시를
새 비디오 요청에 전달한다. 기존 입력과 음성은 보존하고 다시 켜면 입력을 복원한다.
기존 음성과 샘플은 **기존 음성 보관**에서 재생할 수 있고, 씬 구성의 시간 측정용 TTS는 유지한다.

캐릭터 자료를 연결한 비디오 프롬프트 요청 시 저장된 특징을 답변별로 고정한다.
이후 원본 특징을 바꾸면 비디오 프롬프트를 다시 요청해야 반영된다.
영상 생성 요청에는 화자별 특징, 대사 원문, 감정과 클립 내 발화 시간을 포함한다.
오디오 미지원 모델, 클립 경계를 넘는 대사, 영상 길이를 벗어나는 대사는 생성 전에 차단한다.
실제 목소리 반영 정도와 클립 사이 음색 일관성은 생성 영상에서 확인해야 한다.

## 이전 작업의 별도 음성 제작 흐름

아래는 기존 별도 음성 작업을 유지하기 위한 흐름이다. 새로운 캐릭터 설정 화면은 위 설명 기반 흐름을 사용한다.

캐릭터 설정 작업 결과의 **나레이션·캐릭터 목소리 선택**에서 모델·목소리·언어·속도·말투를 저장한다.
내레이터도 같은 화면에서 관리한다. 최초 기본값도 먼저 저장한 뒤 **목소리 샘플 생성**을 누르고,
샘플을 끝까지 재생한 후 **샘플을 듣고 이 목소리 선택**을 누른다. 샘플 생성은 유료 API를
사용할 수 있으며 오디오 워커가 처리한다. 설정 저장만으로 생성하지 않는다.
목소리·말투·속도·모델이 바뀌면 해당 설정의 샘플을 다시 선택해야 한다. 서버는 현재 목소리와
일치하는 같은 workspace의 선택 완료 샘플을 검증하며, 듣기 여부의 최종 판단은 사용자에게 있다.
비디오 프롬프트 작업 결과의 **음성·음악 제작**에서 원본 캐릭터 작업과 답변 버전을 선택해
가져온다. ID가 같은 캐릭터에 연결하며 제목으로 자동 추정하지 않는다. 가져온 값은 독립적인
설정 스냅샷이므로 원본 목소리 설정이 바뀌어도 소급 변경되지 않는다.

새 비디오 프롬프트 답변은 `audio_plan`의 speakers/cues로 화자, 발화 원문, 전체 영상 기준
시작·종료 시간, 감정을 제안한다. 기존 답변은 수정하지 않으며 수동으로 화자·발화를 추가할 수 있다.
공통 지침은 관리자, 2D·3D·실사 연출 지침은 기존 에이전트 설정 권한을 따른다.

1. 비디오 작업에서 별도 제작을 켜고 캐릭터 작업에서 선택 완료한 목소리를 가져와 화자·발화·음원 설정을 저장한다.
2. 발화별 **음성 생성**을 누른다. 이 동작은 외부 API 비용이 발생할 수 있다.
3. 실제 음성 길이와 전사문을 확인하고 듣고 확정한다. 할당 시간 초과나 원문 불일치는 확정할 수 없다.
4. 모든 영상 클립도 확정한 뒤 **합성 미리보기 만들기**를 누른다.
5. 결과를 확인하고 최종본을 확정·다운로드한다. 이전 파일과 원본 클립은 유지한다.

새 별도 제작 모드의 영상 생성은 audio=false다. 이미 소리가 있는 영상은 원본 소리 제거에
명시적으로 동의한 뒤 합성한다. 합성은 사용 길이만큼 클립을 컷 연결하고, 음성과 배경음악을
하나의 타임라인에 배치한다. 음악의 시작 위치·시작/종료 시각·음량·반복·페이드·대사 중
음량 감소를 설정할 수 있다. 실제 영상이 계획보다 짧으면 합성을 거절한다.

배경음악 업로드는 최대 16MiB/10분이며 WAV·MP3·OGG·FLAC·M4A/MP4·AAC의 실제
디코딩을 확인한다. 음원은 workspace 내부 보관함에 저장한다. 외부 음원 검색·음악 생성,
목소리 복제, 자동 립싱크·디졸브·자막 합성은 포함하지 않는다.

## 서버 설정과 워커

`.env.example`에 `ASA_AUDIO_AI_ENABLED`, `ASA_AUDIO_API_KEY`, `ASA_AUDIO_DAILY_CALLS`,
`ASA_AUDIO_MODEL_PROFILES` 예시가 있다. 기본 생성은 꺼져 있다. API 키는 서버에만 저장하고
API/오디오 워커를 재시작한다. 기본 프로필은 OpenAI Realtime 음성 출력이다.
모델·voice 허용 목록은 서버 모델 프로필에서 관리한다. OpenAI 계정의 실제 모델 사용 권한과
한국어 발음/품질은 실제 생성으로 별도 확인해야 한다.

상단 **오디오 워커** 상태를 눌러 기존 워커 관리 모달에서 시작/작업 완료 후 중지한다.
CLI는 `./scripts/run.ps1 audio-worker`. 로컬 FFmpeg 합성에는 음성 API 키가 필요 없다.
비활성화되거나 일일 한도를 넘은 음성 대기 작업 때문에 로컬 합성까지 멈추지는 않는다.

음성 요청은 호출 전에 DB에 claim을 저장한다. 실행 중 끊긴 작업은 unknown으로 남기고
자동 재호출하지 않는다. 공급자 사용 내역을 확인한 후 화면에서 새 발화로 다시 준비한다.
합성 실패는 새 작업으로 명시적으로 재시도할 수 있다. 동일 operation ID는 재실행하지 않는다.
음성 생성 내역은 AI 사용량에 기록하지만 현재 정확한 Realtime 토큰 요율/사용량 정산은
연결하지 않았으므로 비용은 **미확인**이다. 무료 또는 0원으로 해석하지 않는다.

# 기존 작업에서 음성 검토

답변 아래 **대사별 음성 확인**에서 재생·시간표·목소리·전사를 확인하고 개별 음성을 확정한다. 선택 답변에 음성이 없으면 `base_version` 계보의 가장 가까운 음성 설정/작업을 표시하며 원본 버전을 안내한다. 기존 음성을 복제하지 않고 원본 job의 확인 상태를 갱신한다. 음성 확인은 답변 버전이나 에이전트 지침을 변경하지 않는다.

원문 불일치·설정 변경·실패 결과는 제외 영역에 보존한다. 배정 시간을 넘긴 음성은 재생할 수 있으나 확정할 수 없다. 다른 분기나 미래 버전의 음성은 자동 연결하지 않는다.

## 씬 시간 측정과 제작 음성 구분

씬의 임시 음성은 `purpose=timing`으로 시간 배분을 검증하는 용도다. 화면에서 재생 가능하지만
제작 확정과 영상 합성에는 사용할 수 없다. 샘플은 `sample`, 최종 제작 발화는 `production`이다.
목적별 생성 지문을 분리해 시간 측정 파일을 제작 결과로 재사용하지 않는다.
최종 목소리/감정을 선택한 후 실제 발화 길이를 다시 측정하고 씬 시간표를 검토해야 한다.
`after_tasks.scene_timing=true`인 씬 에이전트는 새 요청·다시 요청의 답변 저장과 함께
구조화된 `timing_plan`의 발화를 시간 측정용 음성 큐에 넣는다. 기존 답변은 소급 생성하지 않는다.
오디오 워커가 실제 음성을 생성하면 계획의 앞·사이·뒤 여백을 유지하며 순서대로 재배치한다.
본문 원문은 보존하므로 화면의 실측 시간표가 본문의 예상 시간표와 다를 수 있다.
목표 초과를 표시하며 자르거나 배속하지 않는다. 실패·불확실 호출은 자동 재시도하지 않는다.
목표 길이까지 무음을 추가하지 않는다. `timing_plan.planned_duration`은 실제 계획 끝이며
목표 `duration`과 분리한다. 명시된 계획 끝과 실측 발화를 기준으로 구성 길이를 계산하고
측정 완료 후 부족분을 표시한다. 계획 끝이 없는 이전 데이터는 마지막 배정 구간을 사용한다.
계획된 행동·반응 여백은 유지되며 그 필요성을 음성 길이만으로 검증한 것은 아니다.
대사가 없는 계획은 음성을 생성하지 않는다. 최종 제작 음성과 합성 대상에서는 제외한다.
측정용 생성에도 API 사용료가 발생한다. `ASA_AUDIO_AI_ENABLED=true` 및 실행 중인 오디오 워커가
필요하며, `ASA_AUDIO_API_KEY`가 비어 있으면 기존 `ASA_AI_API_KEY`를 사용한다.
모델/목소리는 `ASA_AUDIO_TIMING_MODEL_KEY`(기본 openai-realtime),
`ASA_AUDIO_TIMING_VOICE`(기본 marin)로 설정한다. 생성 큐는 답변 버전별로 분리된다.

측정 음성이 있는 씬 작업은 **시간 배분 확인**을 표시한다. 목표/전체 길이, 음성 실측 합계,
앞뒤·사이 여백, 화자별 타임라인과 단일 전체 플레이어를 제공하며 개별 음성 카드는 표시하지 않는다.
`timing_duration_seconds`가 없으면 마지막 배정구간 기준임을 표시한다. 중첩은 구간 합집합으로
계산하고 누락/겹침이 있는 경우 전체 재생을 차단한다. 목표 초과는 표시하며 음성을 잘라내지 않는다.
인증된 timing-preview 조회는 기존24kHz mono PCM 음성을 시간표 위치에 배치하고 나머지를 무음으로
채운다. 외부 API 호출·음성 재생성·원본 수정 없이 로컬에서 조합한다. 최대3600초다.

## 목소리 특징과 기존 음성

캐릭터 설정에서는 작품 공통 나레이션과 캐릭터별 목소리 특징을 정해 영상 생성에 전달한다. 나레이션은 최초 조회와 임시 입력 복원 시에도 접힌 상태이며 사용자가 펼친다.

기본 예시 음성 재생 UI, 조회 API와 유료 사전 생성 CLI는 제거했다. 이전 음성 보관 영역도 캐릭터 설정에서 제거했으며, 사용자 작업의 기존 음성 데이터는 보존한다. 씬 구성의 시간 측정용 TTS와 전체 미리듣기는 유지한다.
