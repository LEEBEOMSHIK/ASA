# 보관함

기존 `/characters` 경로와 탐색 메뉴 ID는 유지하고 표시 이름을 **보관함**으로 변경한다.
메뉴 강조색과 사이드바 폭 설정은 그대로 유지된다. `?view=scenes` 등 기존 이미지 링크는
이미지 대표본 모아보기로 연결되며 ImageBrowser/ImageTaskManager의 선택·생성·확정 계약은 변경하지 않는다.

## 사용

- 유형별: 기본 대본 최신 카드 목록을 바로 표시한다. 상단의 작은 유형 선택 버튼으로 씬·캐릭터 이미지·씬 이미지·음성·배경음악·영상로 전환한다. 큰 분류 카드 중간 화면은 제공하지 않는다.
- 작품별: 첫 화면에 작품 폴더만 표시한다. 작품을 열면 연결 자료가 나온다. 작품 미지정 자료는 별도 입구로 제공한다. 작품 만들기·이름 수정·자료 연결/해제가 가능하다.
- 검색/유형/작품/상태 필터는 함께 적용된다. 페이지당12/24/48개(기본24), 모든 저장 버전을 표시한다.
- 카드 클릭: 내용 또는 파일 미리보기, 같은 작업의 자료·버전 이동, 다운로드. 목록 카드는 자료 유형·제목·작업명·날짜·상태를 표시하며 원래 작업 이동과 작품 연결 관리는 상세보기 안에 둔다. 긴 제목은 카드에서 두 줄, 상세에서 전체 표시한다.
- 수정·재생성·확정은 원래 작업 링크에서 한다. 보관함 조회로 승인 상태를 변경하지 않는다.
- 배경음악과 생성 음성은 서로 다른 유형으로 표시한다. 영상은 클립·최종 합성·참고 영상을 구분한다.

## 기존 자료와 분류

기존 답변(script_versions), 캐릭터/씬 이미지, 참고 이미지 업로드, 영상 클립,
삭제된 작업에서 보관한 영상, 참고 영상 파일/링크, 음성/합성 작업, 배경음악,
자동화 성공 단계의 출력(직접 AI 포함)을 원본 저장소에서 읽는다. 파일 복제나 재생성은 없다.
알려진 출력 계약을 우선 분류하고, 과거 텍스트 답변은 실행 당시 저장된 에이전트 역할명으로
대본/장면 등을 분류한다. 판별할 수 없는 결과도 기타 자료에서 조회된다.

작품 제목으로 자동 병합하지 않는다. 저장된 대본/장면 입력과 기존 답변 전체 또는 필드의 원문 일치(80자 이상, JSON은 키 순서 정규화)를 따라 작품을 자동 표시한다. 동일 원문 출처가 여러 작품으로 갈리거나 순환하면 합치지 않는다. 가져온 뒤 원문을 수정한 경우의 유사도 추정은 하지 않는다.
현재 입력에서 출처를 확인하지 못하면 source_id 재작업 관계를 사용한다. 재작업하면서 다른 대본을 선택한 경우에는 현재 대본의 출처가 우선한다. 자동화 결과를 사용한 작업은 해당 자동화 실행 작품으로 이어지고, 해당 요청의 이미지·음성·영상은 작품을 상속한다. 명시적인 참고 영상 source_id도 사용 작품이 하나일 때 연결하며 여러 작품이 공유하면 미지정에 보존한다. 캐릭터 이미지 공유만으로 서로 다른 작품을 합치지 않는다.
자동 작품 ID는 workspace와 원본 작업 ID로 결정하므로 새로고침/기기 변경에도 동일하다. 작품명은 원본 제목을 사용한다. 자동 분류 조회는 원본이나 분류 테이블을 수정하지 않는다. 기존 수동 분류/해제는 우선 보존한다. 예외 자료는 자동 작품에도 수동 연결할 수 있고 이때만 분류 메타데이터를 저장한다. 자동 작품은 원본 작업에서 이름을 관리한다.

작품과 연결 정보는 workspace 범위 DB 테이블(library_works/library_assignments)에 저장되어
같은 작업 공간의 다른 기기에서도 유지된다. 사용자별 작업 표시 이름은 기존 정책을 따른다.
변경은 CSRF 보호 및 revision 충돌 검사를 거친다. 잘못된 workspace 자료/작품 연결을 거부한다.
연결 해제에도 revision을 남겨 오래된 저장으로 되살아나는 것을 방지한다.

## 한계

현재 로컬 규모에 맞춰 요청/자료 메타데이터를 workspace 단위로 모은 뒤 검색·페이지 분할한다.
목록에는 바이너리·작업 프롬프트를 넣지 않으며 본문과 미디어는 상세에서 읽는다.
대규모 SaaS 도입 시 SQL 인덱스 기반 통합 조회로 전환하고 부하를 검증해야 한다.
보관된 삭제 작업 영상에는 원래 승인 상태가 남아 있지 않아 확정으로 추측하지 않고 보관됨으로 표시한다.
이전 답변 가져오기는 현재 텍스트만 저장하므로 수정된 원문/짧은 발췌는 출처를 자동 복원할 수 없다. 출처 ID를 영구 기록하는 계약은 후속 개선 대상이다. 서버가 분류를 위해 기존 본문을 읽지만 목록 응답에 원문을 포함하지 않는다.

탐색 메뉴는 archive 보관함 전용 아이콘을 사용한다. 유형별/작품별 전환 시 이전 필터와 페이지를 초기화한다. 상세에서는 현재 유형/작품명과 돌아가기를 표시한다. 이미지 자료 카드에는 썸네일을 표시하고, 날짜·원래 작업 정보의 중복을 줄인다.
자료 목록은 필터 적용 후 페이지당12/24/48개를 선택한다(기본24). 개수 변경 시 첫 페이지로 돌아가며 기존 검색·유형·작품·상태 필터는 유지한다. 이전/다음은 접근성 이름과 툴팁을 가진 화살표 아이콘이며 현재/전체 페이지 수를 표시한다. 한 페이지에 모두 표시되면 이동 버튼을 숨긴다. 작품 폴더 목록은 현재 전체 표시이며 별도 페이지네이션은 없다.

작품 카드·작품 필터·연결 선택 목록에는 원본 에이전트/자동화 이름, 원본 요청 생성 일시, 저장된 길이·스타일 context를 표시한다. 답변 생성 일시와 구분하며 없는 정보는 추측하지 않는다. 연결 목록의 ‘현재 연결’은 저장된 연결을 나타낸다. 같은 제목은 닫힌 선택란에서도 설명을 함께 표시하고, 설명까지 동일하면 짧은 구분 번호를 추가한다. 직접 만든 작품은 원본 정보 대신 ‘직접 만든 작품’으로 표시한다. 제목 일치만으로 작품을 병합하지 않는다.

## 결과물 단위의 유형

미디어의 `kind`는 이미지·오디오·영상 재생용 계약을 보존한다. `category`는 실제 저장 자료의 subtype으로 정하며 캐릭터 이미지/씬 이미지/참고 이미지/음성/배경음악을 분리한다. 생성 에이전트 이름은 미디어 분류에 사용하지 않는다. 기존 image/audio 필터는 호환용 전체 조회이고 화면은 세분화된 유형만 제공한다.

캐릭터 설정 문서, 해당 작업에서 생성한 캐릭터 이미지와 음성은 각자 독립된 자료 ID·미리보기·상태·유형별 개수를 갖는다. 동일 작업의 작품 연결은 유지한다. 상세의 같은 유형 자료 목록도 category로 제한하여 캐릭터 이미지와 씬 이미지가 섞이지 않는다. 원본 파일·승인·수동 작품 연결은 변경하지 않으며 별도 마이그레이션이 필요 없다. 대표 이미지·버전 모아보기는 선택한 이미지 종류로 진입하고 기존 ImageTaskManager를 재사용한다.

탭과 작품별 유형 선택은 대본·씬·캐릭터 이미지·씬 이미지·음성·배경음악·영상의7종만 제공한다. 캐릭터설정/참고이미지/비디오프롬프트/기타자료는 탭에서 제외하며 원본자료와 작품연결은 보존한다. 작품 전체 목록에서 기존자료는 계속 확인할 수 있다. 각탭은 서로다른 아이콘+이름+개수를 함께 표시한다.

## 작품 상세 유형 탐색
작품을 열면 대본/씬/캐릭터 이미지/씬 이미지/음성/배경음악/영상 탭이 해당 작품 개수와 함께 표시됩니다. 첫 방문은 대본, 없으면 자료가 있는 첫 유형을 엽니다. 기존의 다른 유형도 전체 자료에서 볼 수 있습니다. 작품 목록으로 나갔다 돌아오면 선택 유형·검색·상태·페이지·표시개수가 복원됩니다(화면을 새로고침하거나 보관함 페이지를 떠나면 초기화).
대본·씬은 원문 일부를 발췌하고 이미지는 썸네일을 표시합니다. 음성·영상 파일은 카드 내 별도 컨트롤로 재생하며 상세 보기에서 버전·원문·다운로드·작품 연결에 접근합니다. 원본/자동 분류는 변경하지 않습니다.

## 동일 결과와 씬 연결 자료
같은 자동화 실행·같은 작품에 속하며 본문이 정확히 같은 출력은 대표 한 건으로 표시합니다. 다른 실행이나 내용이 다른 결과는 합치지 않습니다. 원본 DB와 기존 상세 ID는 유지하며 상세의 '같은 결과의 저장 위치'에서 각각 확인합니다.
씬 이미지 제작 계획은 실제 scene 프로젝트 또는 shots 결과+scenes 입력 계약으로 식별합니다. 같은 작품 안에서 입력 원문과 유일하게 일치하는 씬이 있을 때 그 씬의 연결 자료로 표시합니다. 모호한 연결은 독립 자료로 유지합니다. 제목만으로 합치지 않습니다. 목록·유형 개수·작품 개수·페이지네이션은 대표 자료 기준이며 연결 계획은 씬 상세에서 열고 원래 씬으로 돌아갈 수 있습니다.
