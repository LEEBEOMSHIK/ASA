# 에이전트 등록 사용법

현재 제공 범위는 나만의 에이전트 정의와 도구 등록이다. 등록만으로 AI 호출이나 비용은 발생하지 않는다.

1. 로컬 DB·API·웹을 실행하고 `/agents`를 연다. 현재 PC 주소는 http://127.0.0.1:3001/agents 이다.
2. `/login` 관리자 로그인 페이지에서 `.env`의 ASA_OWNER_ACCESS_KEY로 로그인한다. 로컬 개발 실행에서는 ‘테스트 로그인’으로 바로 접근할 수 있다. 공급자의 API 키를 입력하지 않는다.
3. 새 에이전트에서 대본 작가·아이디어 기획자·대본 검수자 예시를 선택하거나 직접 작성한다. 이름·한 줄 소개·맡길 일을 다듬고, ‘받을 정보/만들 결과’에 필요한 정보의 설명을 적는다. 실제 실행 입력을 넣는 단계가 아니다.
4. 허용할 ASA 도구 또는 이미 확정한 내 에이전트 버전을 선택한다. 자기 자신과 다른 작업 공간 도구는 사용할 수 없다.
5. 초안을 저장한다. 영문 연결 이름·자료형은 ‘항목 추가 및 세부 형식 설정’, 모델·한도는 ‘고급 설정’에서 변경할 수 있다.
6. ‘도구로 등록’을 누르면 서버가 검증하고 작업 공간 내부에 불변 버전과 도구를 생성한다. 오류가 있으면 안내에 따라 수정한다. 외부 공개가 아니다.
7. `/tools`에서 ASA 도구와 내 에이전트를 함께 확인한다. 이후 초안 수정은 과거 확정 버전을 바꾸지 않는다.

동시에 수정된 초안을 덮어쓰려 하면 충돌 오류가 표시된다. 새로 불러오기 전에 필요한 변경 내용을 보관한다.
저장하지 않은 변경이 있으면 화면 이탈 경고와 로그아웃 확인이 제공된다.
세션은 8시간 후 만료되며 로그아웃하면 서버 세션을 폐기한다. 이 owner 로그인은 개인 개발용이며 SaaS 인증을 대신하지 않는다.

현재 대본 길이 검사 도구는 등록 가능하다. 미디어 도구는 준비 중이다.
실행 버튼은 실행 기반이 완성될 때까지 비활성이다. LLM 도구 선택·호출 트리·비용·승인·블록 연결은 후속 작업이다.
모델 공급자·모델명·비밀키는 서버 설정으로 관리하며 사용자 정의 코드나 임의 HTTP 도구는 받지 않는다.

입력·출력은 제한된 JSON Schema를 사용한다. 깊이4, 필드50, 배열100, 인라인64KiB 상한을 적용한다.
새 에이전트의 결과는 기본 ‘자유로운 답변으로 받기’다. 필요한 경우만 ‘항목별로 받기’를 선택한다.
기존 결과 항목은 자동 변경하지 않는다. 결과의 내용은 실행 후에 알 수 있으며 실행 전에는 빈 결과 자리만 표시한다.
확정 시 객체의 추가 필드를 차단하고 문자열·배열·숫자 범위를 정규화한다.
화면에서 기본 필드·중첩 묶음·기본형 목록을 편집할 수 있다. 모든 JSON Schema 기능을 제공하는 편집기는 아니다.

2번의 ‘실행할 때는 이렇게 사용해요’에서 대본 작가·기획자·검수자의 입력값과 결과 예시를 비교할 수 있다.
고정 설명 예시이며 현재 에이전트의 실제 실행 결과가 아니다. 예시 전환은 설정을 변경하지 않는다.
3번은 ‘ASA 기본 도구’와 ‘내가 만든 에이전트’로 나뉘며 둘을 동시에 선택할 수 있다.
3번의 ‘ASA 기본 도구’와 ‘내가 만든 에이전트’ 제목을 각각 눌러 독립적으로 펼치거나 접는다.
2번의 ‘실행 화면 미리보기’에서 현재 초안으로 만든 입력 화면을 직접 체험할 수 있다.
입력 확인은 브라우저 내부 동작이며 실제 AI 실행·서버 전송·저장은 하지 않는다.
편집으로 돌아오면 체험 입력은 지워지고 에이전트 설정은 유지된다. 실제 실행 엔진은 아직 미연결이다.
각 그룹에 선택 개수와 선택 불가 이유를 표시한다. 선택은 사용 권한이며 호출 순서는 아니다.

실제 로그인·저장·검증·버전 확정을 확인한 ‘샘플 · 채널 대본 작가’가 로컬 작업 공간에 있다.
샘플은 기능 확인용이며 실제 AI 생성 결과가 아니다.
