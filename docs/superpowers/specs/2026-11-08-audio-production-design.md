# 목소리·음원·영상 별도 합성 설계

상태: 사용자 승인 후 구현. 실제 유료 생성은 미실행. 구현 범위와 검증/미검증은 ../../audio-production.md 참조.

## 선택한 방향

사용자는 영상 모델의 오디오에만 의존하는 대신, 목소리 고정·음원 선택·별도 합성을 선택했다. 영상은 무음으로 생성하며 음성/음악을 독립 자산으로 보관하고 최종 영상으로 합친다. 기존 영상과 대본을 변경하지 않고 새 버전으로 만든다.

## 사용 화면과 연결

1. 캐릭터 설정 작업의 캐릭터 상세에 목소리 선택·말투·속도·언어를 제공한다. 캐릭터의 안정된 ID에 연결하며 이름 변경으로 목소리가 끊기지 않는다. 캐릭터 설정이 없는 작업에서도 화자를 직접 등록할 수 있다.
2. 비디오 프롬프트 작업에 `음성·음악 설정`을 둔다. 연결된 캐릭터 목소리를 가져오고, 내레이터 목소리와 배경음악을 선택한다. 명시적인 원본 작업 ID/버전으로만 가져오며 제목이 같은 작업을 자동 연결하지 않는다.
3. 배경음악은 없음 또는 업로드한 음원 보관함에서 선택한다. 파일 이름·길이·미리듣기·시작 구간·음량·반복·페이드 설정을 제공한다. 첫 구현에서 외부 음원을 자동 검색하거나 음악 생성 API를 호출하지 않는다.
4. 비디오 프롬프트의 공통 지침에 화자 ID·원문 대사/내레이션·시작/종료 시간·감정·효과음 제안을 포함한 오디오 계획을 추가한다. 2D/3D/실사 지침은 연출 차이만 보강한다. 사용자가 화면에서 검토·수정한 구조화 계획이 생성 입력이 된다.
5. `음성 생성 → 미리듣기·확정 → 클립 영상 확정 → 합성 미리보기 → 최종본 확정/다운로드` 순서로 제공한다. 설정 저장으로 유료 작업이 자동 시작되지 않는다. 영상 생성은 음성 확정 뒤 실측 길이에 맞춰 진행할 수 있게 안내한다.
6. 전체 작품에서 하나의 음악 타임라인을 사용한다. 클립마다 음악을 새로 시작하지 않는다. 내레이션이 없는 구간, 음악 없음, 대사와 내레이션만 있는 작업도 지원한다.

## 공급자와 생성 정책 (제안)

- 첫 음성 공급자는 기존 OpenAI 연결 구조를 활용하되 별도의 음성 모델 프로필/서버 비밀 설정으로 관리한다. 현재 지원 모델·voice 목록을 관리자 설정으로 관리하고 클라이언트에 키를 전달하지 않는다.
- 2026-11-08 확인한 공식 Speech API 문서는 기존 tts-1/gpt-4o-mini-tts 계열의 종료 예정과 신규 연동용 Realtime API를 안내한다. 구형 Speech API를 새 구현의 고정 기본값으로 쓰지 않는다. 구현 시 현재 권장 Realtime 모델과 음성 출력 계약을 재확인한다.
- 캐릭터마다 공급자/모델/voice ID/지침을 고정한다. 동일 voice ID를 사용해도 모든 발화의 음색·감정이 완전히 동일하다고 보장하지 않는다. 생성 결과를 사용자가 미리듣고 확정한다.
- 복제 목소리는 첫 범위에 포함하지 않는다. 공급자 기본 목소리 선택과 사용자가 준비한 음원 업로드부터 연결한다. 립싱크 자동 보정도 별도 기능이며 음성 합성과 구분해 표시한다.
- 기존 영상 모델의 audio=true는 새 별도 합성 모드에서 false로 고정한다. 기존 작업은 변경하지 않으며 이미 소리가 있는 원본 영상은 최종 합성에서 원본 소리 제거 여부를 명시적으로 표시한다.

## 데이터와 서비스

- workspace 범위 audio assets: 업로드/생성 파일, SHA256, 형식, 실제 길이, 화자/요청/버전, 생성 모델 스냅샷.
- audio settings: 비디오 작업별 캐릭터 voice 매핑·내레이터·음원·믹싱 설정과 revision. 캐릭터 설정을 가져온 뒤에는 스냅샷을 저장해 나중의 변경이 이미 생성된 작업에 소급되지 않는다.
- audio cues: cue ID, 화자 ID, 대사 원문, timeline 시작/끝, 감정/속도, 생성 자산 ID, 검토·확정 상태.
- audio jobs / composition jobs: queued/running/succeeded/failed/unknown 상태, 요청 idempotency 키, 설정/자산 버전 스냅샷. 불확실한 유료 호출을 자동 재시도하지 않는다.
- API는 인증·CSRF·workspace·파일 크기/형식·권한/참조 버전을 검증한다. 서비스는 타임라인 적격성과 확정 규칙을 담당한다. 로컬 워커가 외부 음성 호출과 FFmpeg 합성을 수행한다. UI에서 별도 오디오 워커 시작/작업 완료 후 중지를 제공한다.
- 자산 경로는 서버가 생성하고 사용자 경로/URL을 FFmpeg 입력으로 직접 받지 않는다. 업로드 실제 디코딩과 길이를 확인하고 명령은 인수 배열로 실행한다. 임시 파일과 결과는 Git에서 제외한다.

## 시간과 합성

- 생성 음성의 실제 길이를 측정한다. 할당 구간을 넘으면 `시간 조정 필요`로 표시하고 최종 합성을 막는다. 임의 대사 삭제·음성 잘라내기·무리한 속도 변경은 하지 않는다.
- 짧은 음성은 남은 구간을 무음으로 채운다. 동일 화자의 겹치는 발화, 누락된 voice/음성 파일, 잘못된 구간, 미확정 또는 변경된 영상은 명시적으로 검증한다.
- 기본 출력은 확정 클립 순서에 따른 컷 연결, 음성 시간 배치, 음악 구간/반복/페이드/음량 조정, 말하는 구간 음악 낮추기다. 기존 continue 클립의 참조 확정 규칙을 유지한다.
- 최종 합성은 원본 클립·음성·음악을 보존한 새 MP4다. 이전 최종본도 보존한다. 원본 버전이 바뀌면 새 조합으로 다시 합성하며 기존 결과를 최신으로 오인하지 않게 한다.

## 검증과 완료 조건

- 공급자 요청 계약은 모의 API로 검증, 기본 단위/통합 테스트에 유료 호출 없음.
- 권한/격리·중복 접수·재시작·응답 불확실·버전 충돌·오디오 off·누락 화자·음성 초과/겹침 검증.
- 합성은 테스트 전용 영상과 음원으로 실제 FFmpeg 출력의 길이/오디오 스트림/구간과 재생 확인.
- 브라우저에서 캐릭터/내레이터 선택, 음원 없음/업로드/선택, 미리듣기, 시간 초과, 생성/확정/합성 상태를 양테마·좁은 화면으로 확인. 사용자 자료를 시각 검사 목적으로 임의 확정하지 않는다.
- 실제 음성 품질/한국어 발음과 공급자 사용 권한은 별도의 사용자 승인 생성으로 검증한다. 모의 테스트 통과를 실제 AI 품질 검증으로 보고하지 않는다.
