# 관리자 로그인 분리

사용자 요청: 별도 관리자 로그인 페이지와 개발 중 바로 접근할 수 있는 테스트 로그인 버튼.
기존 owner 로그인은 유지하고 `/login`으로 이동한다. 미인증 관리 화면은 로그인으로 이동하며
로그인 후 allowlist로 제한된 관리 경로로 돌아간다. 로그아웃은 /login으로 이동한다.

테스트 로그인은 서버가 development 환경이며 명시적으로 허용했고 loopback 요청인 경우만 제공한다.
접근 키를 클라이언트에 주입하는 방식 대신 서버에서 기존과 동일한 세션을 발급한다.
기본·운영 설정은 비활성이고 Docker에서 production을 명시한다. 로컬 run 스크립트만 활성화한다.
버튼에는 기존 로컬 작업 공간을 사용하는 개발 기능임을 표시한다. 별도 데모 데이터는 만들지 않는다.

검증 순서: 운영/비활성/외부 요청 거절 테스트 → 개발 세션·CSRF·로그아웃 테스트 → 구현 →
pytest/ruff/mypy/typecheck/build → 실제 로그인·복귀·로그아웃 UI 확인.
