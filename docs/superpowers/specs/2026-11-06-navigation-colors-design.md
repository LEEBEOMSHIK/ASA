# 사용자 메뉴 강조색

사용자는 메뉴별 강조색과 기본값 초기화, 기존 폭 유지, PC·모바일 동기화를 선택했다. 브라우저 전용 저장은 제외한다.
서버는 인증된 workspace/user에 메뉴별 팔레트 색과 revision을 저장한다. 메뉴별 갱신으로 서로 다른 메뉴의 수정은 충돌하지 않으며 같은 메뉴의 오래된 수정은 409로 차단한다. 프로필 저장 계약은 변경하지 않는다.
밝음/어두움에 맞춘 6개 팔레트와 기본색을 제공한다. 강조색은 아이콘·옅은 배경에 적용하고 현재 메뉴는 별도 테두리로 구분한다. PC 우클릭/Shift+F10과 모든 기기의 설정 → 메뉴 강조색에서 공통 dialog를 연다. 명시 저장 전 변경은 임시 미리보기다. 로그인 후, 화면 복귀 및 설정 열기 때 최신 서버 값을 조회한다. 서버 실패를 로컬 성공으로 처리하지 않는다.
