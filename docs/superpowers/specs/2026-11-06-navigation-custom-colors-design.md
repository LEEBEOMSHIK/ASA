# 메뉴 강조색 자유 팔레트

사용자 승인안: 기본6색에 브라우저 색상 팔레트와 HEX 입력을 추가한다. 기본색 초기화와 서버 동기화·기존60px 폭을 유지한다. 선택 원색은 서버에 #rrggbb로 저장하고 기존 이름색도 호환한다. UI는 밝음/어두움 각각 원색에서 옅은 배경과 4.5:1 이상 대비를 갖는 전경을 유도한다. 원색은 팔레트에서 그대로 확인한다.

빠른 선택의 마지막 항목은 직접 선택이다. 팔레트와 HEX 입력은 같은 행에 두며 높이44px, 입력 간격12px와 섹션 간격16px를 토큰으로 유지한다. 형식 오류에서는 저장을 막고 설명을 표시한다. 브라우저 기본 색상 선택기는 기기별 UI를 사용한다. 미리보기·선택 상태·오류·취소·테마와360px 화면을 검증하며 사용자 저장값을 검증용으로 변경하지 않는다.
