# 에이전트 편집 UX 개선

문제: 개발 계약을 그대로 나열해 처음 접한 사용자가 입력 목적과 다음 행동을 알기 어렵다.
외형 변경만으로는 해결되지 않아 안내형 단일 페이지를 채택한다. 여러 페이지의 마법사는
이미 작성한 내용을 비교하기 어렵고 기존 편집 동작을 크게 바꾸므로 이번 범위에서 제외한다.

역할 예시 선택 → 맡길 일 설명 → 받을 정보와 만들 결과 확인 → 저장/도구 등록 순서.
새 에이전트만 예시를 제공한다. 기존 자료를 자동 교체하지 않는다.
스키마 description으로 사람이 읽을 설명을 편집하며 기존 필드 키와 자료형은 보존한다.
영문 키·복합 자료형·모델·실행 한도는 고급 설정으로 접는다.
설정 요약은 실제 AI 결과처럼 표현하지 않는다. 실행 기능 미구현 상태를 유지한다.
공통 토큰과 UI로 로그인·목록·편집의 색상, 간격, 계층을 정리한다.

검증: 기존 API 검사 전체, frontend typecheck/build, 브라우저 예시 선택·설명 수정·저장,
등록과 기존 버전 보존, 키보드와 좁은 화면에서 주요 조작 확인.
