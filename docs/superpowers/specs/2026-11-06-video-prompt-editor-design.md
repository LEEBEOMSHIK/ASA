# 영상 스타일별 에이전트 지침 편집

## 사용자 정정 · 최종 계약
- 최종 추가 정정: 선택 기능을 켜는 체크박스/수동 모드를 제거한다. 영상 스타일을 실행 입력에서 필수 선택하면 기본 동작으로 공통+선택 스타일 본문을 합성한다. 설정은 본문만 편집한다. 영상 모델 입력 계약 또는 기존 화면 관리 설정을 기반으로 영상 에이전트를 판별하며 이름 문자열로 판별하지 않는다. 미작성 스타일은 설정 저장은 허용하되 실행은 차단한다. 기존 설정 편집 시 입력 계약을 준비하고 저장 필요를 안내하며 원문·DB를 임의 변경하지 않는다.
- 기존 `instructions`가 공통 지침이다. 별도 공통 입력/독립 카드 없이 **기본 설정 안**에서 그 아래 스타일별 추가 지침을 관리한다.
- 새 실행은 기존 에이전트 지침을 공통으로 1회 + 선택 스타일 본문으로 합성한다. `common_instructions`는 호환 데이터로만 보존하고 새 합성에 사용하지 않는다. 이전 queued catalog/bundle은 원래 동작을 유지한다.
- 일반 사용자는 화면 관리 에이전트의 기존 instructions 변경 및 editor_managed 제거를 할 수 없다. 관리자만 공통을 편집한다. 아래 최초 설계의 별도 공통 필드/3계층 구성은 이 정정으로 대체한다.

사용자 승인: 실행 화면이 아니라 에이전트 설정 편집에서 스타일별 지침을 수정한다. 관리자는 같은 화면에서 공통 지침도 수정한다.

기존 AgentDraft.video_prompt_modules에 에이전트별 공통/2D/3D/실사 본문을 보존한다. 별도 실행 입력 override나 개인 프리셋은 만들지 않는다. 기존 instructions는 삭제하거나 자동 이동하지 않는다. 화면 편집 모드를 명시적으로 켜고 공통 본문과 적용 스타일을 설정해야 활성화한다.

일반 사용자는 스타일별 본문을 편집하고 owner/admin만 공통 본문을 변경한다. API를 우회한 요청도 repository의 잠금/수정 트랜잭션 안에서 비교하여 차단한다. 현재 로컬 계정은 owner이며 일반 사용자 역할은 격리 테스트로 검증한다.

수동 스타일 또는 기존 입력 매핑 기반 자동 선택을 제공한다. 실행은 공통 → 선택한 스타일 → 기존 에이전트 지침 순서이며 개별/자동화의 기존 snapshot 경로를 사용한다. 저장 이후 새 요청에만 적용한다. 빈 지침으로 활성화하거나 잘못된 자동 선택 필드를 저장하지 못하게 한다. UI 저장만으로 유료 API를 호출하지 않는다.

대안: 실행 화면에서 일회 수정하는 방식은 사용자가 명시적으로 제외했다. 전역 파일 편집은 화면 관리/에이전트별 저장 요구에 맞지 않아 기존 파일 방식은 호환용으로만 유지한다.

공통 토큰, 확대 편집, 단일 저장, 충돌 처리와 작업 공간 경계를 유지한다. 실제 사용자 지침을 검증 목적으로 저장하지 않는다.
