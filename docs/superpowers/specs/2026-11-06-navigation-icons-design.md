# 접힌 메뉴 식별 개선

사용자가 선택한 안은 현재 폭을 유지하고 고유 아이콘과 hover/focus 이름 안내를 제공하는 것이다. 항상 이름을 표시하는 안은 작업 영역을 줄이므로 선택하지 않았다.

공통 StudioNavigation의 모든 목적지에 서로 다른 도형을 배정한다. 접혀 글자가 보이지 않을 때만 portal 안내를 표시해 부모의 overflow에 잘리지 않도록 한다. 포커스·마우스 진입 시 표시, Escape/탐색/스크롤 시 닫기, 안내 위로 포인터 이동 유지, viewport 경계 보정이 필요하다. 모바일과 펼친 메뉴는 기존 텍스트를 유지한다. 탐색 대상·권한·폭·사용자 데이터는 변경하지 않는다.
