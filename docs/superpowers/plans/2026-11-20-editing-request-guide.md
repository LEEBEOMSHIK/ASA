# 편집 요청 구성과 가이드 Implementation Plan

**Goal:** 내부 영상·업로드 영상·씬 이미지 혼합 선택과 이해하기 쉬운 편집 요청 가이드.
**Architecture:** 기존 편집 선택/계획 계약 유지. 기존 video_references 파일 저장 재사용, reference 소스 허용. 글 입력은 x-editing-brief로 가이드/예시 추가.
**Tech Stack:** 기존 FastAPI/Pydantic/React/FFmpeg.

- [x] reference 영상 선택·workspace·계약·스냅샷 검증 및 테스트.
- [x] 파일 업로드/드래그/파일 붙여넣기와 내부 자료 선택, 요청 가이드·덧붙이는 예시.
- [x] 등록 에이전트의 새 버전 입력/지침 갱신, 기존 자료·답변 유지.
- [x] 모바일/양테마 실제 브라우저, 전체 검사 및 기록. 실제 AI 호출/영상 합성 없음.

외부 URL 다운로드는 이번 범위 제외: 파일을 우선 지원한다고 사용자에게 설명. 이미지 영상화는 표시시간·확대축소이며 캐릭터 동작 생성 아님. 기존 요청을 덮어쓰지 않는 예시 추가, 지원하지 않는 전환·음성통일을 약속하지 않음.
