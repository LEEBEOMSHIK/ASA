# 작품 공통 화풍 구현

사용자 승인 범위: 상단 공통 화풍을 모든 연결 캐릭터/씬 이미지에 적용하고 기존 자료를 보존한다.

1. 기존 library.index의 작품 연결 결과를 재사용하여 workspace+work_id 단위 설정을 저장한다. 이름으로 합치지 않는다. revision 충돌과 프로젝트 권한을 검증한다. 명시적으로 연결이 해제된 작업은 연결 안내만 표시한다.
2. 이미지 접수 시 공통 화풍의 값/작품ID/revision을 immutable job에 보관한다. 단일/일괄 생성 모두 같은 enqueue를 사용한다. 공통 화풍은 스타일에 한해 appearance/image_prompt/AI제안/수정요청/참조 이미지보다 우선하며 비스타일 내용은 원래 우선순위를 유지한다. 미설정은 기존 prompt를 그대로 유지한다. 이미지 검수에도 생성 당시 공통 화풍을 전달한다.
3. 공통 UI를 캐릭터/씬 상단에 배치한다. 저장/기본 방식 복원(빈 값 저장), 오류, 저장 후 접기, 임시 입력 보존. 기존 AI 지침과 우선순위 안내, 이미지 버전별 적용 snapshot 확인.
4. 실제 이루리 원본 요청→답변→이미지 지침을 읽기 전용 확인한다. 격리 DB로 공유/분리/권한/revision/멱등/프롬프트를 검증, 전체 pytest/ruff/mypy/typecheck/build, 브라우저 밝음/어둠/좁은 화면 확인. 유료 생성 및 사용자 자료 임의 저장은 하지 않는다.
