# 캐릭터 참고 이미지 업로드 계획

사용자가 승인한 보관함 선택 + 직접 업로드 흐름을 확장한다. 기존 선택 계약을 유지하고 서버에서 저장된 불변 이미지/캐릭터 설정을 재검증한다. 기존 캐릭터 선택 시 확정 설정을 복사하고, 새 캐릭터는 이름과 외형·의상을 필수로 받는다. 최대 12장, PNG/JPG/WebP 5MB, 서버 디코딩·크기 제한·메타데이터 제거. UI 제거는 연결만 해제하고 저장 자료는 보존한다.

- [x] 파일/연결 검증 테스트와 업로드 저장·workspace 검증 서비스
- [x] 보관함 조회/선택 계약 확장 및 실제 모델 이미지 전달 회귀 테스트
- [x] 업로드/드롭·미리보기·캐릭터 연결/수정·제거 UI
- [x] 로컬 화면 밝게/어둡게/모바일 확인 및 필수 검사

유료 호출은 하지 않고 모델 메시지를 가로채 실제 이미지와 설정 전달을 검증한다. 기존 워킹 트리와 사용자 데이터를 보존한다. 커밋은 이번 요청 범위에 없다.
