# 사용자·역할·메뉴 권한 관리

사용자 승인: 관리자가 역할을 추가하고 사용자에게 부여하며 메뉴 접근과 기능 권한을 관리한다. 기존 local-owner와 자료는 유지한다.

## 구현
1. workspace별 역할, 사용자, 감사 이력을 추가한다. 기존 세션의 사용자 열은 local-owner로 기본 설정한다. 소유자 역할은 변경 불가하다.
2. 사용자명/비밀번호 로그인(해시 저장), 계정 중지, 비밀번호 변경 시 세션 폐기, 요청마다 역할 재조회. 기존 소유자 키 로그인은 유지한다.
3. 권한 카탈로그로 메뉴 조회와 수정·생성·검수·확정·삭제를 구분한다. 등록되지 않은 API는 일반 사용자에게 기본 거부한다. 기존 하드코딩된 관리자 검사도 기능 권한으로 연결한다.
4. 관리 화면에서 역할/사용자를 추가·수정하고 변경 이력을 확인한다. 기존 웹/모바일 내비게이션은 동일 권한 목록으로 필터링한다. 직접 URL도 차단한다.
5. 작품은 현재 workspace 공유 모델을 유지한다. '본인 작품만'은 현재 자산/참조/자동화 전 경로에 소유권 격리가 없으므로 동작하지 않는 선택지를 노출하지 않는다. 이 제한을 완료 보고에 명시한다.

## 검증
- 비로그인, 다른 workspace, 권한 없는 직접 API, 메뉴 없는 실행 권한, 기존 세션 권한 회수, 비밀번호 변경/계정 중지, owner 보호, 수정 충돌 검사.
- backend pytest/ruff/mypy, frontend typecheck/build.
- 브라우저 실제 관리 화면 데스크톱/모바일·밝은/어두운 테마 검증. 보지 못한 상태는 명시한다.
- 실제 AI/영상 생성 없이 검증한다. 사용자 비밀번호·검증 계정·생성 자료를 Git에 저장하지 않는다.
