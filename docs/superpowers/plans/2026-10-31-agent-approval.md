# 에이전트 답변 확정과 UI 정렬

사용자가 요청한 범위: 입력 항목 정렬 수정, 고정 A 아이콘 교체, 실제 사용자 확정 설정 및 실행 연결.

- AgentDraft.requires_approval(default false)를 버전 스냅샷에 저장. 기존 버전은 설정 미사용으로 유지.
- 개별 실행의 기존 approved_version API를 사용자 답변 확정 UI에 연결. 최신 답변만 확정, 생성 중/dirty 제한, 수정 후 재검토.
- work_progress는 답변 검토와 이미지 검토 그룹을 결합. 하나라도 미완료이면 전체 완료로 표시하지 않음.
- 자동화 실행 승인은 기존 검토 노드로 설정함을 도움말에 명시. 이번 플래그는 개별 에이전트 실행의 답변 확정 계약.
- 공통 Field 레이블 행 높이 통일, 도움말/힌트 유무와 무관한 입력 상단 정렬. 네이티브 summary 삼각형 대신 공통 chevron.
- 카드의 고정 A를 공통 에이전트 SVG로 교체, 카드 하단 정렬.
- 설정 저장/등록/이전 버전 보존/답변 확정 및 재수정/복합 후속 작업 통합 테스트. 유료 호출 없음.
