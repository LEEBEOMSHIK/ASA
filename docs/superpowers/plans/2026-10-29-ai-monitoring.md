# AI 사용량·요청 추적 구현 계획

승인 범위: 관리자 전용 내부 모니터링, 원래 요청 → 실행 → 호출 추적, 공급자 반환 토큰·시간·예상 비용. 외부 추적 서비스 없이 PostgreSQL에 저장한다.

- [x] 호출별 이벤트와 요율 스냅샷, 비밀값 마스킹, 사용량 미확인 처리 구현.
- [x] 자동화 직접/예약 실행 및 고객 대본/CLI 호출에 수집 연결. 요청자·원래 입력을 보존하고 요청 전문은 상세 조회에서만 제공.
- [x] owner/admin 권한·workspace 격리 API, 기간/출처/모델/상태/검색 필터, 전체 집계와 페이지 목록 구현.
- [x] 관리자 GNB 모니터링 화면: 요약, 모델·자동화 집계, 호출 상세. 실제 데이터가 없으면 빈 상태.
- [x] 모의 호출 사용량/오류/캐시/요율 변경/권한·격리·페이지 테스트, 전체 필수 검사, 로컬 DB 마이그레이션 및 화면 검증.

요율은 USD/백만 토큰 설정값이며 현재 가격을 임의로 하드코딩하지 않는다. 미등록 요율과 검색 도구 추가 비용은 미확인으로 표시한다. 캐시 읽기/생성 요율 없으면 해당 비용 계산을 보류한다. 호출 시작을 먼저 기록하고 중단 시 미확인 상태를 보존한다. 비밀값/공급자 오류 원문/HTTP 헤더는 저장하지 않는다. 로컬 소유자 인증 모델을 유지하고 SaaS 인증 완성으로 주장하지 않는다. 실제 유료 호출과 커밋·푸시는 이번 검증에서 하지 않는다.
