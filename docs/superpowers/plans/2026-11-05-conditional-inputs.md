# 입력 조건부 필수 구현
- 입력 필드에 x-required-when {field, equals}를 저장한다. 같은 최상위 입력의 선택지 또는 boolean을 비교한다.
- 항상 필수와 조건부 필수 중복, 자기 참조, 삭제된 항목/선택지, 중첩 조건 위치를 저장 시 거절한다.
- 공통 평가 함수를 단독 실행과 자동화 검증에 적용한다. 비교는 타입을 구분하며, 조건이 참이면 빈 글·빈 목록을 거절한다.
- 편집기는 항상 필수/조건부 필수/선택 및 조건 항목·선택값을 제공한다. 참조 항목 삭제는 연결 조건을 먼저 해제하도록 안내한다.
- 실행 화면은 값 변경에 따라 필수 표시와 검증을 갱신한다. 입력한 선택 자료는 유지한다.
- 회귀 테스트 후 실제 밝은/어두운 1280px·390px 화면에서 설정, 미리보기, 스크롤, 검증·오류 상태를 캡처한다. 실제 사용자 설정과 결과는 QA로 저장하지 않는다.
