# 보관함 중복 결과와 씬 연결 자료

사용자 승인: 원본 보존, 동일 자동화 실행의 동일 출력은 하나로 표시, 이미지 제작 계획은 원래 씬의 연결 자료로 표시. 모든 작품에 공통 적용.

- [x] 조회 전용 표시 투영 구현: 동일 실행+정확한 JSON 본문 기준 중복, 기존 ID의 상세 접근 유지.
- [x] scene 이미지 프로젝트 또는 shots+scenes 입력 계약으로 제작 계획 식별. 같은 작품의 씬 원문과 입력이 유일하게 일치할 때만 연결.
- [x] 대표 카드·집계·페이지는 투영 기준. 상세 모달에 연결 자료와 같은 결과의 저장 위치 제공.
- [x] 자동화 간/상이 본문/모호한 연결/원본 보존 테스트. 실제 이하나 씬1개 및 연결 계획1개 확인, UI·필수 검사 기록.
