# 대본 단계 구현

사용자 승인 범위: 고객 화면에서 단계별 결과를 보고 필요한 단계만 수정/재실행. 우선 대본.

1. 기존 요청 상세에 대본 제작 진입을 추가한다. 기존 임의 에이전트 결과를 대본으로 추정하거나 덮어쓰지 않는다.
2. request/workspace에 묶인 대본 단계와 불변 버전, 확정 버전, 재작성 요청을 DB에 저장한다.
3. 직접 편집은 새 버전, AI 요청은 원본 버전/지시/등록 에이전트 정보를 고정한다. 확정은 현재 버전에만 적용한다.
4. API는 검증·권한·대기 요청 저장을 담당한다. 유료 호출은 명시 실행 CLI 워커에서만 한다.
5. LangGraph가 대본 생성/출력 검증 흐름을 수행하고 LangChain의 기존 Script 계약을 사용한다.
6. UI는 대본 상태·결과·편집·이전 버전 비교·재작성 범위·확정 상태를 보여준다. 후속 단계는 준비 중이다.
7. DB 격리·충돌·멱등성·워커 성공/실패를 외부 호출 없는 테스트로 검증하고 전체 검사와 브라우저를 확인한다.

실행 제한: 범용 큐·비용 원장·자동 상시 워커는 이번 범위가 아니다. 요청 저장만으로 유료 호출하지 않는다.
AI 결과가 불확실한 실행은 자동 재시도하지 않는다. 호출 후 DB 저장 전 장애는 별도 운영 확인이 필요하다.
에이전트의 도구 호출은 아직 지원하지 않으며, 연결 도구가 있는 에이전트는 대본 AI 실행을 차단한다.
