# 시간 배분 확인

승인된 설계: timing 음성은 대사별 카드 없이 전체 요약, 화자별 발화구간, 간격 포함 단일 WAV 미리듣기. production 검토는 유지한다. 새 유료 TTS 자동 생성은 이번 범위 밖이며 현재 씬 실행은 텍스트 결과만 생성한다.

명시적 목표 시간은 timing_duration_seconds에 보관, 없으면 마지막 배정구간 기준으로 표시하고 목표로 오인하지 않는다. 발화실측구간의 합집합으로 여백을 산출하며 중첩과 누락은 별도로 안내한다. 잘못된 음성은 제외, 누락/중첩 상태에서는 오해의 소지가 있는 전체 재생을 차단한다. 시작·사이·끝 무음을 보존하며 음성을 자르거나 배속하지 않는다.

1. 순수 시간표/PCM 조합 테스트 및 인증 endpoint 회귀.
2. audio_timing 서비스, review metadata 및 WAV endpoint. 같은 workspace와 실제 버전계보만 사용.
3. SceneTimingReview 컴포넌트/토큰 CSS. 대사별 플레이어 제거.
4. 현재 측정 결과의 명시적30초 목표 기록(음성파일/답변 보존), 브라우저 검증 및 필수검사.
