# 캐릭터 이미지 보관함과 선택 입력 구현 계획

목표: 사용자 승인한 이미지 카드 중심 보관함과 씬 이미지 입력 선택 연결. 기본은 캐릭터마다 확정 이미지 또는 최신 성공 이미지, 이전 버전은 상세에 둔다. 작업·에이전트·상태 필터와 이름 검색을 제공한다.

설계: 기존 character_projects/image_jobs 데이터 보존. workspace 범위 서버 목록 API(페이지 단위)와 선택 API를 추가한다. 여러 작업의 확정 이미지도 선택할 수 있도록 명시적인 선택 전달 형식을 추가하며, 서버가 선택된 이미지의 확정 설정을 구성한다. 실행 직전 재검증 후 실제 이미지 첨부. 기존 전체 프로젝트 handoff 형식은 그대로 지원한다. 클라이언트는 공통 이미지 목록을 보관함과 입력 선택창에 재사용한다.

- [x] backend character_library.py: 목록/필터/선택/출처와 확정 검증. 위조·제외·이전 확정·workspace·페이지 경계 실패 테스트 후 구현.
- [x] character_handoff.py: 새로운 명시적 선택 객체를 서버 원본과 비교해 첨부. 기존 전체 전달 유지. 선택 캐릭터만 포함하고 대본/씬 불변 테스트.
- [x] character-library.tsx/css: 이미지 카드·검색·필터·확대/버전 확인·원래 작업 이동. 모바일·다크 토큰, 키보드 포커스/닫기 지원.
- [x] agent-input.tsx: 이미지 참조 스키마 인식 후 JSON 대신 이미지 선택 입력. 선택 취소·오류·최대12장·선택 목록 유지.
- [x] 씬 템플릿과 로컬 해당 에이전트의 참조 입력 계약만 확장. 지침과 다른 에이전트 변경 없음.
- [x] 전체 pytest/ruff/mypy/typecheck/build, 실제 UI 및 로컬 선택 데이터 전송 검증. 유료 호출 없음, 커밋/푸시 없음.

검토 중점: 새 검토본이 생긴 이전 확정본의 선택 차단, excluded 이미지 보존 및 전달 차단, 다른 프로젝트의 동일 캐릭터 ID 구분, 느린 검색 응답의 순서 역전, 좁은 화면의 카드/필터/모달 경계.
