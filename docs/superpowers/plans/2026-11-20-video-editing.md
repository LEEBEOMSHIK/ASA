# 영상 편집·합성 Implementation Plan

**Goal:** 기존 클립과 씬 이미지를 선택해 AI 편집 계획을 받고, 확정 후 별도 합성본 출력.
**Architecture:** 등록 에이전트의 기존 답변 버전/승인/실행 큐 재사용. 새 편집 계약과 결과 UI를 추가하고, 로컬 FFmpeg 합성은 기존 오디오 워커가 처리한다. 원본 미디어와 기존 AI 생성 경로는 변경하지 않는다.
**Tech Stack:** FastAPI, PostgreSQL, Pydantic, Next/React, FFmpeg/Pillow.

## 범위와 선택
사용자가 승인한 편집 계획→검토→출력 흐름을 구현한다. 별도 유료 영상 재생성은 하지 않는다. 기존 합성은 모든 영상 소리를 제거하므로 원본 음성 유지와 이미지 영상화를 지원하는 별도 렌더 경로를 추가한다. 새로운 워커 프로세스는 만들지 않는다.
- 타임라인 최대32항목/총10분, 세로·가로·정사각720p/1080p, 원본 비율은 패딩으로 유지.
- 클립 자르기·음량, 이미지 표시시간/완만한 확대축소, 컷/검정 페이드, 자막, 기존 확정 음성/음악 배치. 새 음성 생성은 기존 음성 기능에서 수행.
- AI는 제공된 자료 메타데이터와 대본/씬을 참고. 영상 내용을 직접 시청했다고 주장하지 않음.
- 실제 사용자의 자료로 유료 호출/렌더는 실행하지 않고 합성 테스트용 미디어만 사용.

- [x] 자료 선택 입력/타임라인/확정·출력·미리보기 UI 및 에이전트 등록.
- [x] 실제 브라우저 모바일·양테마/전체 pytest ruff mypy typecheck build 검증과 기록.

## 위험 검증
다른 workspace 자료, 확정되지 않은 자료, 잘못된 길이/오디오 없음, 변경된 계획/소스, 중복 접수/중단 작업, 자막 문자열을 명령으로 실행하지 않는지 검증한다. 합성 완료는 자동 확정하지 않는다.

검증 결과와 미검증 범위는 WORKBOARD.md의 영상 편집·합성 완료 항목 참조. 실제 사용자 자료로 AI/합성은 실행하지 않았다.
