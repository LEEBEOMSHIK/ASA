# 영상 분석 에이전트 구현 계획

**Goal:** 영상 파일 및 공개 YouTube/Instagram Reels를 실제 화면 근거로 분석하고 비디오 프롬프트의 선택 참고 자료로 연결한다.

**Architecture:** workspace별 원본 업로드/링크 기록을 저장한다. 기존 실행 워커에서 다운로드·프레임 추출 후 실제 이미지 첨부로 분석한다. 긴 작업은 API에서 수행하지 않는다. 분석 결과는 일반 에이전트 답변으로 저장하고 기존 이전 작업 선택 기능을 사용한다.

**Tech Stack:** FastAPI/PostgreSQL, FFmpeg, yt-dlp, LangChain, Next.js.

- [x] 파일/URL 검증, workspace 격리, 워커 전처리, 실제 이미지 첨부 테스트 작성 및 구현
- [x] 파일 드롭·링크 입력과 제한/분석 범위 안내 구현
- [x] 영상 분석 지침/템플릿 등록, 비디오 프롬프트 선택 입력 연결 (기존 지침 보존)
- [x] 합성 영상 전처리와 전체 테스트, 실제 UI 확인. 외부 접근 및 유료 분석 미검증 여부 기록

결정: 초기 범위는 5분/20MiB 영상, 시간 순서의 최대24개 프레임이다. 음향은 분석하지 않는다. 프레임 사이 움직임/편집은 추정으로 구분한다. 링크 실패 시 업로드를 안내하며 로그인 우회·쿠키 입력은 제공하지 않는다. 원본 사용자 업로드를 임시파일 정리 대상으로 취급하지 않는다.
