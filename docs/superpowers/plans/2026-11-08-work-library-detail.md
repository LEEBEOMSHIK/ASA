# 작품 상세 보관함 구현 계획

**Goal:** 승인된 작품 상세 디자인을 유형별 탭과 매체별 미리보기로 구현한다.
**Architecture:** 기존 library index/lineage와 자료 ID, 미디어 URL, 상세 API를 유지한다. 작품 범위의 개수와 제한된 원문 발췌만 조회 응답에 추가한다. 작품별 탐색 상태는 현재 화면에서 기억하며 DB의 작품·자료를 수정하지 않는다.
**Tech Stack:** Next.js/React, 공통 UI·토큰, FastAPI/PostgreSQL.

## 승인된 구성
- 작품명·목록 복귀, 아이콘/개수를 포함한 7개 유형 버튼. 기존 기타 자료 접근은 전체 자료 버튼으로 보존.
- 최초 대본 우선, 없으면 자료가 있는 첫 유형. 작품별 탭/검색/상태/페이지 크기/페이지 기억.
- 대본·씬은 원문 발췌, 이미지 큰 썸네일, 음성/영상은 별도 재생 컨트롤. 버튼 안에 재생 컨트롤을 중첩하지 않는다.
- 상세 모달의 버전·연결·원문 접근 유지. 자동연결/원본/사이드바 폭 변경 없음.
