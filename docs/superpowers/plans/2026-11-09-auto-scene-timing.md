# 씬 답변 이후 측정 음성 자동 연결

사용자 승인: 새 요청/다시 요청 후 시간 측정 음성 및 전체 미리듣기 자동 연결, 답변정보/비교버튼 간격 유지.

명시적 after_tasks.scene_timing 설정을 실행 snapshot에 보존한다. 해당 실행만 AI 응답 envelope에 timing_plan(목표초, 화자, 원문발화/시각)을 추가하고 본문 출력 계약은 유지한다. 자유문장 정규식/에이전트 이름으로 역할을 추정하지 않는다. 저장 트랜잭션에서 답변 버전별 timing설정과 UUID5 발화작업을 접수한다. 같은 작업 재전송/워커 재시작으로 유료호출을 반복하지 않는다.

오디오 워커는 기존 한도·중단·원문일치 검증을 사용한다. 계획 시간과 실측은 구분, 초과·중첩은 숨기거나 자동으로 배속하지 않는다. 화면은 생성상태를 주기적으로 확인하며 완료시 전체미리듣기로 전환한다. 측정용 음성은 최종확정 금지. 기존 답변/음성은 소급 생성하지 않는다.

검증: provider 출력 계약, 최초/재요청 각 버전 큐, 중복방지, 실패/누락/권한, mock TTS 전체미리듣기. 필수 전체검사와 브라우저 양테마/좁은화면/메타정보간격 검증. 신규 실유료호출은 테스트에서 하지 않는다.
