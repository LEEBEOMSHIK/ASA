# 자동 작품 분류
사용자가 승인한 방향: 재분류를 필수로 요구하지 않고 제작 관계를 작품별 보기에 투영한다.
1. library_lineage.py에 workspace 내부 요청/답변의 원문 일치 및 source 계열 해석 구현. 제목은 식별자가 아니다. 다중 출처/순환은 보수적으로 처리.
2. library.index에 자동 작품 연결. 원본 요청 ID로 안정적인 auto ID, 원본 제목 사용. 기존 수동 지정/해제 우선. 생성 미디어는 요청의 작품을 상속. 자동화는 실행 단위.
3. UI 자동 연결 표시와 자동 작품 원본 이동, 수동 편집 API로 자동 ID 전송 방지.
4. 단위/DB 회귀 및 실제 자료 read-only 분류 집계. 필수 전체 검사와 UI 확인, 원본 데이터/분류 테이블 무변경.
