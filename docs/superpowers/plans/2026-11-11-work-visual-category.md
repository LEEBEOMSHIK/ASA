# 작품 공통 영상 유형과 화풍

사용자 요청: 작품 공통에서 2D/3D/실사를 먼저 선택하고 호환 화풍을 표시한다. 선택은 이미지, 비디오 프롬프트와 실제 영상 생성까지 공유한다. 기존 자료는 보존한다.

1. work_art_styles에 nullable media_type 추가. 미설정 기존 데이터는 추측하지 않는다. 이미지 snapshot/prompt에서 영상 유형을 화풍보다 우선한다.
2. 명시적으로 선택한 씬/캐릭터 이미지의 서버 프로젝트를 통해 작품 설정을 resolve. 복수 작품의 다른 설정은 거절. 비디오 요청의 입력과 모듈 조합은 작품 유형으로 일치시킨다. 당시 설정은 script_attempts 계약에 고정한다.
3. 비디오 생성은 답변 당시 snapshot을 사용하고 최신 작품 설정과 다른 계획은 새 비디오 프롬프트 요청을 안내한다. 이미 접수한 영상은 불변.
4. 공통 UI에서 유형 → 화풍 순서. 2D: 수채화/2D/웹툰, 3D:3D/클레이, 실사:실사. 직접 입력 지원. 기존 미분류 화풍은 보존. 실행/재요청 UI에서 작품 설정을 불러와 독립 선택 충돌을 방지한다.
5. 공유·격리·snapshot·모듈 선택·변경 충돌 회귀 테스트, 필수 검사와 브라우저 간격/반응형 검증. 실제 유료 생성은 실행하지 않는다.
