# Focused automation builder

사용자가 승인한 화면 방향을 적용한다: 목록과 편집 분리, 중앙 순차 흐름, 사이 추가 버튼,
선택한 블록의 설정만 표시, 상단 이름/저장/테스트, 기술 용어 축소.
기존 API/초안/검증/테스트 계약은 유지한다. 범용 자유 배치 캔버스는 범위 밖이다.
1. 기존 편집 상태를 보존하며 목록/편집 전환과 단계 삽입 UI를 구성한다.
2. 기본 닫힘 설정 패널과 native dialog 선택창을 사용해 키보드·초점 복귀를 유지한다.
3. 토큰 기반 CSS·문서 갱신, 전체 필수 검사와 브라우저 저장/삽입/모바일 검증.
