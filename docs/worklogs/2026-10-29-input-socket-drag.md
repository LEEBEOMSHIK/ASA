# ASA-046 입력 연결점 이동 오류

- 원인: 드래그 중 경로는 이동 시작 시점의 스냅샷을 사용하지만 입력점 CSS 위치는 스냅샷의 절대 y에서 현재 블록 y를 빼고 있었다. 블록을 이동할수록 연결점이 반대 방향으로 이탈했다.
- 수정: inputSocketOffset에서 스냅샷 기준 상대 위치를 계산하고 입력점과 임시 연결선 끝점 양쪽에서 공유한다. 합류 포트 간격과 저장 그래프는 유지한다.
- 회귀: 두 연결이 합류하는 블록을 상하/좌우로 이동할 때 포트가 카드 안에 머무르고 선 끝점과 일치하는지 검사한다.
- 브라우저: 제어 도구의 browser.user is unavailable 오류로 실제 드래그 재검증은 미수행.
- 검증 완료: 경로 테스트20개, pytest123개, ruff, mypy28개 파일, frontend typecheck/build 통과. OS 런처 차단으로 Python 도구는 python -m 방식으로 실행했다. 실제 유료 AI 호출 없음.
