# ASA-032 자동화 빌더 정보 구조 개선

기존 초안 API와 기능은 유지하고 목록과 편집 화면을 분리했다.
기본 편집 화면은 상단 이름/저장 상태/저장/테스트와 중앙 흐름만 표시한다.
단계 사이 ＋를 눌러 검색 가능한 에이전트/도구 dialog를 열며 선택한 위치에 삽입한다.
작업 선택 시 해당 설정만 표시하고, 연결 테스트는 별도 요청 시 표시한다. 둘 다 닫을 수 있다.
작은 화면에서는 선택한 설정 영역으로 초점을 이동하고 스크롤한다. 임의 모델 결과를 생성하지 않는다.

검증: 전체 check.ps1 pytest43개·ruff/mypy 통과. 초점 보완 후 웹 typecheck/build 재통과.
브라우저 기존 샘플 중간에 도구 추가/제거 후 원래 연결 유지, 서버 구성 검증,
샘플 대본 전달→로컬 길이 검사9자 결과, 저장 및 목록에서 재열기 확인.
360/768px document scrollWidth=clientWidth, native dialog Escape 닫기와 추가 버튼 초점복귀 확인.
밝은/어두운 화면 시각 검수. 사용자 자동화 내용은 변경하지 않았고 기존 샘플은 같은 내용으로 재저장했다.
실제 AI 실행/유료 호출/외부 배포/커밋 없음. 전체 스크린리더 검사는 미수행.
