# 씬 구성의 제작 리듬 지침

공통 규칙 원문: [scene-production-pacing.md](../agent-templates/scene-production-pacing.md).

- 기존 장면 구성 템플릿의 10~14장면 및 2~3컷 기본 예시를 제거했다. 대본의 사건과 공개 순서를 유지하면서 목적이 있는 전환만 추가한다.
- 음성·쉼·반응 시간을 먼저 배분하며, 겹치는 행동과 순차 행동을 구별한다. 실제 음성 미측정 여부 및 목표와의 충돌을 숨기지 않는다.
- scene_id/cut_id와 generation_group_id를 구분하고 잠정 생성 묶음의 대응 컷·사용 구간·생성 길이·시작/종료 상태·연결 및 모델 확인 사항을 작성한다. 편집 여유분은 완성 영상 시간과 별도다.
- 지침은 생성 모델의 길이 제한·다중 숏 지원을 가정하지 않는다. 후속 비디오 프롬프트에서 선택 모델과 확정 자료를 바탕으로 최종 확정한다. API 실행 계약 자체를 바꾼 것은 아니다.
- 로컬의 사용자 지정 씬 구성 에이전트 revision7→8 저장. 다른 설정과 기존 답변 보존, 최신 저장 버전에 지침이 포함됐음을 확인했다. 원본 백업은 Git 제외 .local/diagnostics/scene-pacing에 보존했다.
- 이후 새 작업 접수에 적용된다. 이미 접수된 작업·기존 답변·이전 버전으로 다시 작업은 기존 스냅샷을 사용하므로 새 지침 검증은 새 작업에서 수행한다.
- 실제 AI 재생성 및 TTS 시간 측정은 이번 변경에서 수행하지 않았다. 지침 적용이 실제 생성 품질을 보장하지는 않는다.
