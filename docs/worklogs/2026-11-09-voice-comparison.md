# 기본 음색과 샘플 비교

- 기본 음색에 한글 이름과 공급자 ID를 함께 표시한다. 알 수 없는 공급자 음색은 원래 이름을 유지한다.
- 원하는 목소리·말투 직접 요청에 한국어 예시와 적용 범위를 안내한다. 기존 instructions 전달 계약을 유지한다.
- 서버의 공통 샘플 문장을 화면에 표시하고, 같은 화자의 샘플 이력을 음색·말투·언어·속도·시각과 함께 비교한다. 다른 문장의 과거 샘플은 구분한다.
- 이전 샘플 설정 불러오기는 초안만 변경한다. 저장 후 정상 샘플을 끝까지 듣고 선택하며 서버의 fingerprint/권한/revision 검증은 유지한다. 불러오기·선택은 AI를 호출하지 않는다.
- 기존 사용자 설정과 결과는 변경하지 않았다. 실제 유료 샘플 생성 없음.

## 검증

- 확장 통합 테스트: 같은 문장으로 두 음색 생성(mock), 샘플 설정/본문 노출과 내부 input 미노출, 현재 설정과 다른 샘플 선택 거절, 이전 설정 복원·재선택, 추가 AI 호출 없음.
- 전체 pytest 470통과(206.49초), Ruff/mypy 84파일/typecheck/build 통과.
- 실제 이루리 캐릭터 작업의 빈 샘플 상태: CSS1600px 양테마·기본 음색 옵션·포커스·비활성 생성 버튼 확인. 두 열 입력 시작 높이 일치, 높이44px, grid/섹션gap16px, 안내gap12px.
- CSS433px 단일 열, 가로 넘침 없음 DOM 확인. 모바일 스크린샷은 CDP timeout으로 미확보. 테마와 viewport는 복원하고 새로고침 후 dark/1600 확인.
- 증거: `.local/diagnostics/voice-compare/dark.png`, `dark-comparison.png`, `light.png`.
- 실제 작업에 샘플이 없으므로 생성된 비교 카드·재생 완료/선택·오류 상태의 실제 브라우저 검증은 미실시. 관련 동작은 테스트 DB에서 모의 음성으로 검증했다.

- 단일 AudioProduction 상태의 portal로 나레이션을 캐릭터 목록 위에 한 번 표시한다. 캐릭터 상세는 현재 캐릭터만 표시한다. 사용자 설정/작품 결과 저장 없음.
- 실제 기본 샘플 생성: gpt-realtime-2.1-mini 10음색, 호출11회(시더 최초 실패 후 명시적1회 재시도), 정상 파일10개. 원가/청구액 미확인. 기본 재생은 추가 AI 호출 없음. 앞 절의 유료호출없음은 이전 작업에 해당한다.

- viewport 원상복구 후 CSS1600/dark 확인. 커밋/푸시 없음.

## 공통 나레이션 접기
- 접기/펼치기 버튼은 aria-expanded/aria-controls로 패널 상태를 전달한다. 접혀도 음색·언어·속도, 저장/샘플 확인/목소리 선택 상태와 오류·알림은 보인다.
- 저장된 나레이션은 초기 접힘, 미설정은 펼침. 저장 성공 및 나레이션 목소리 선택 성공 시 자동 접힘. 실패 시 패널 상태 유지. 캐릭터 전환으로 공통 토글을 초기화하지 않는다.
- 실제 저장된 작업에서 초기 접힘과 수동 펼침/접힘 확인, dark1600 높이 약123px/header gap12px, 좁은433 가로넘침 없음 확인. 증거 `.local/diagnostics/narration-collapsed.png`. 사용자 설정을 저장하지 않아 저장 성공/실패 후 자동 전환은 코드 경로 확인만 수행. 밝은 테마와 최종 badge 폭 보정은 실화면 미검증.
- API 호출/자료 변경 없음. 최초 pytest 로컬DB 연결 및 build 폴더생성은 sandbox 권한 제한, 허용된 재실행으로 검증.
- 최종 검증: pytest473(172.58초), Ruff/mypy85/typecheck/build/diff-check 통과. 커밋/푸시 없음.

## 맞춤 샘플 상태 구분
- 공통 voiceSampleStatus로 나레이션 요약·펼친 나레이션·캐릭터 목소리 상태를 통일했다. 미생성은 중립색, queued/running은 생성 대기/중, 정상 review/approved는 듣고 선택, 서버 선택 화자는 선택 완료로 표시한다. 실패/호출 불명확/전사 오류는 별도 상태다.
- 해당 화자의 저장된 설정과 초안을 비교해 저장 전 변경을 우선한다. 다른 캐릭터 수정만으로 나레이션 상태가 미확인으로 바뀌지 않는다. current=false인 과거 샘플은 현재 상태 판정에서 제외한다. 서버의 듣기/선택 권한·검증은 변경하지 않는다.
- Node 상태 판정 회귀 테스트: 미저장/미생성/queued/running/review/approved/failed/unknown/selected/변경된 selected/전사 오류 검증 통과. 단위테스트 외부호출 없음.
- 실제 dark1600 기존 작업에서 공통 요약·펼친 나레이션·캐릭터 모두 미생성 문구와 neutral badge 확인. header gap12px, 접힌 높이123px. 증거 `.local/diagnostics/voice-sample-status.png`. 생성 중·선택 완료·실패의 실제 화면 및 밝은/좁은 화면은 이번 작업 미검증(순수 상태 판정 테스트로 확인). 사용자 자료 저장/실제 AI 호출 없음.
- 최종 전체 pytest473(172.51초), Ruff/mypy85/typecheck/build/diff-check 통과. 커밋/푸시 없음.
