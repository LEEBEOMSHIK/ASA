# ASA-084 사용자 입력 양식

- 입력 항목 편집기: 표시 이름, 짧은 글/긴 글/숫자/라디오/선택 목록/정수 슬라이더, 선택지, 최솟값/최댓값, 필수 여부, 기본값, 추가/삭제.
- 기본값은 새 실행에만 적용한다. 이전 요청의 재실행에서는 당시 실제 값을 그대로 불러온다. 빈 선택 항목은 보내지 않는다.
- input_schema에 description/enum/default/x-widget/minimum/maximum을 저장한다. DB 변경 없이 초안·등록 버전이 설정을 보존한다. 이름 변경은 기존 연결 키를 바꾸지 않는다.
- 기존 중첩·목록 입력은 세부 형식 편집을 유지한다. 슬라이더는 정수 단위1을 지원한다.
- 공통 AgentInput으로 실행/미리보기를 렌더링한다. 라디오 그룹의 legend, 슬라이더 label/output·방향키, 기본44px 영역과 색상 토큰 적용.
- 서버는 입력 방식과 자료형, 빈/중복 선택지, 범위·기본값을 검증하고 실행 시 enum/필수/숫자 범위 위반을 거부한다.
- 고객·자동화 AI 메시지에 input_schema를 함께 전달하여 field_1 같은 키의 사용자 표시 이름과 범위를 알 수 있게 한다.

## 검증
- 선행 테스트에서 지원하지 않는 default/x-widget으로 실패 확인 후 구현.
- 입력 계약 단위6개, 저장·등록·입력 검증 통합1개 통과.
- 전체 pytest173 통과(154.27초). 마지막 입력 설명 전달 변경 후 관련8개 통과, 공급자 단위5개 통과(추가 단위1개 포함). 이 추가 테스트의 최초 실패는 모의 정의에 limits가 빠진 테스트 자료 오류였으며 보완 후 통과했다.
- src ruff/mypy34, frontend typecheck/build 및 diff check 통과.
- 브라우저 미저장 폼: 대상 시청자 라디오(어린이/청소년/성인), 무서운 정도 슬라이더(1~5, 기본2), 소재 선택 목록(기본 자동) 구성 후 미리보기 자동 반영 확인. 청소년/3/유령으로 변경해 입력 확인 결과 일치 확인. 유료 AI 호출0.
- 스크린샷 .local/verification/agent-input-form-preview.png. 샘플 폼은 검증용 미저장 상태로 사용하고 사용자 에이전트 정의는 변경하지 않았다.
- 실행 중 호출0 확인 후 로컬 API·개별 실행 워커·자동화 워커 재시작.
