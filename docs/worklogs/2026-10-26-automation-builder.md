# ASA-030 자동화 구성 화면

요청에 따라 자동화 실행 엔진보다 구성 화면을 먼저 구현했다.
`/automations`에 초안 목록·에이전트/도구 블록 선택·순서 변경·단계명·입력 출처 설정·초안 저장을 제공한다.
서버는 workspace·CSRF·revision 충돌을 검사한다. 등록 버전 ID를 저장하고 미래/누락 참조를 거부한다.
구성 검증과 연결 테스트를 분리했다. 샘플 에이전트 답변과 실제 로컬 길이 검사 결과를 구분한다.

## 확인

- 로컬 DB migration 적용, 기존 자료 보존.
- 브라우저에서 에이전트 → 길이 검사 도구 구성/입력 매핑/저장/검증/샘플 테스트 확인.
- 샘플 대본 23자가 실제 검사 도구에 전달되어 characters=23, limit=300, exceeded=false 표시.
- 새로고침 후 저장 초안 열기·재저장 성공. 360px 가로 넘침 없음.
- 코드 검토에서 정수형과 최소 길이/enum/목록 길이 검증 누락을 찾아 회귀 테스트와 함께 수정.
- 검증용 자동화 초안 1건은 로컬 DB에 남겼다. 실제 AI 호출/게시 없음.

## 범위 제한

순차 구성 전용. 드래그 캔버스·조건·병렬·게시 버전·실제 AI 실행·실행 원장은 미구현이다.
시작 입력은 요청 문자열 하나, 결과 항목 선택은 최상위 필드까지 제공한다.
복합 객체/배열 직접 값과 샘플은 JSON 입력을 사용한다. 테스트 값은 저장하지 않는다.
고객 제작 단계와 자동화 정의의 통합은 실행 엔진 연결 시 후속 수행한다.
전체 검사 결과는 WORKBOARD ASA-030에 기록한다. 커밋·push 없음.
