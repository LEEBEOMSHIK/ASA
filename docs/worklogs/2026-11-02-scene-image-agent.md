# ASA-161 씬 이미지 에이전트

## 등록 범위

- 로컬 에이전트 ID: `eed35913-04f5-444f-a6a1-f42f31d9567b`.
- 정의: `docs/agent-templates/scene-image-planner.json`.
- 기존 저장 서비스로 실행 가능한 설정을 등록했으며 기존 6개 에이전트의 ID·revision·draft가 모두 그대로임을 비교했다.
- 기본 모델 상속, 이미지 아이콘, 사용자 확정 필요. 이미지 생성 도구나 자동화는 자동 실행하지 않는다.

## 입력과 출력

- 필수: 장면 구성 원문, 확정 캐릭터 전달 객체, 화면 비율(기본 9:16).
- 선택: 공통 화풍, 추가 연출 요청.
- 출력: 제작 계획 요약, 장면/컷 목록, 생성 전 확인 사항. 각 컷에는 원문 구간·등장인물 ID·확정 이미지 ID·구도·이미지 제작 지침·연속성·영상 연출 메모·준비 여부가 포함된다.
- 원문과 장면 순서·대사·사건은 보존한다. 없는 인물을 추가하거나 제외된 인물을 임의 복원하지 않는다. 원문에서 필요한 인물이 확정 목록에 없으면 해당 컷을 준비 안 됨으로 표시하도록 지침에 명시했다.
- 단일 장면의 대표 이미지가 기본이고 필요한 경우에만 원본 scene_id를 유지하며 세부 컷을 제안한다.

## 연결과 제한

- 자동화에서는 기존 ‘확정 캐릭터 가져오기’ 도구의 전체 결과를 `characters` 객체 입력에 연결한다. 필요한 캐릭터 모두 확정 또는 사용 안 함 처리가 선행되어야 한다.
- 기존 자동화 런타임은 전달 객체를 재검증하고 확정 이미지를 첨부할 수 있다. 단독 에이전트 실행은 텍스트/구조화 데이터로 제작 계획을 작성하며 이미지 첨부를 새로 구현한 것은 아니다. 이미지가 없을 때 보았다고 주장하지 않도록 지침에 명시했다.
- 참조 이미지 ID는 이미지 생성 API 첨부 자체가 아니다. 씬별 다중 참조 이미지 생성 도구·생성/수정/확정 UI는 후속 구현이 필요하다. 기존 캐릭터 이미지 도구를 씬 이미지 도구로 가장하지 않는다.
- 실제 유료 AI 실행과 결과 품질 평가는 이번 등록 작업에서 수행하지 않았다.
