# ASA-168 입력 항목별 이전 답변 가져오기 설정

- 고정된 긴 글 표시 규칙을 제거하고 input_schema의 x-previous-answer boolean으로 설정한다. 기본 미지정은 꺼짐이다.
- 에이전트 생성·편집에서 짧은 글/긴 글 항목별 체크박스를 제공한다. 다른 입력 방식으로 바꾸면 설정을 제거한다.
- 직접 입력과 자동화 결과 바인딩은 유지한다. 기존 에이전트의 사용자 지침이나 저장 설정은 변경하지 않는다.
- 화면에서 설정을 켜고 실행 미리보기를 열면 가져오기 버튼 1개가 나타나는 것을 확인했다. 새 에이전트는 저장하지 않았다.
- 전체 pytest 277 passed, ruff/mypy, frontend typecheck/build, diff check 통과. 유료 호출 없음. API 재시작 반영.
- 현재 선택 UI는 작업 목록에서 에이전트 이름으로 검색 후 작업/답변 버전을 선택한다. 입력 설정에서 출처 에이전트를 제한하는 기능은 아직 없으며 사용자에게 범위를 확인 중이다.
