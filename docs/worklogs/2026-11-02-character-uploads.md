# ASA-165 캐릭터 참고 이미지 업로드

## 구현
- 기존 보관함 선택과 직접 업로드를 함께 제공한다. PNG/JPG/WebP 5MB 이하, 한 장씩 이름/외형·의상/선택 제작 지침을 연결한다. 기존 캐릭터 설정도 보관함에서 가져올 수 있다.
- 파일 선택과 드롭이 같은 파일 검증/미리보기 경로를 사용한다. 미리보기, 연결 수정·해제, 필수값 안내, 저장 중 중복 조작 방지, 모바일 한 열과 고정 저장 영역을 제공한다.
- 서버가 이미지를 디코딩하고 16MP 제한, 애니메이션 거절, EXIF 방향 적용, 최대 2048px PNG 변환 및 메타데이터 제거를 수행한다. 업로드 API에만 본문 크기를 확장한다.
- workspace별 이미지와 연결 설정을 저장하고 보관함에 사용자 업로드로 표시한다. 연결 수정은 새 스냅샷으로 저장하며 기존 요청의 참조는 보존한다. 연결 해제는 원본 삭제가 아니다.
- 생성한 확정 이미지와 업로드 이미지를 같은 선택 계약으로 전달한다. 서버 저장 설정을 재검증한 뒤 실제 이미지 바이트를 모델 메시지에 포함한다. 기존 대본/장면 및 생성 캐릭터 설정은 변경하지 않는다.

## 검증
- 전체 backend pytest 268 통과, ruff src 통과, mypy src 50파일 통과.
- frontend typecheck 통과. 최초 build는 standalone 복사 EPERM 경고가 있었고, 권한을 갖춘 재실행은 경고 없이 통과했다.
- 통합 테스트: 로그인/CSRF, 잘못된 파일, 보관함/asset/선택, 타 workspace 차단, 설정 변조 차단, 수정 스냅샷 보존, 모델 입력의 실제 PNG와 설정·대본·장면 원문 확인. 유료 호출 없음.
- Chrome 실제 파일 선택으로 테스트 이미지 저장, 이름 수정 저장, 다시 열기, 연결 해제 후 보관함 검색 보존 확인. 기존 이하나 설정 가져오기 확인(기존 자료 변경 없음).
- 밝은/어두운 테마, 모바일 한 열 레이아웃 확인. 모바일 모달 본문 scrollWidth=clientWidth로 가로 넘침 없음. 임시 viewport와 테마는 복원했다.
- 스크린샷: `.local/character-upload-final-dark.png`, `.local/character-upload-final-light.png` (Git 제외).
- OS 파일을 끌어오는 실제 드래그 제스처는 검증하지 않았다. 드롭 구현은 파일 선택과 동일 처리 함수를 호출한다. 실제 유료 모델의 응답 품질 검증은 이번 범위가 아니다.
- 로컬 DB migration 적용 및 API/관련 워커 재시작. API는 루트 `.env`를 읽는 프로젝트 Python 모듈 방식으로 실행했다.

기존 변경과 사용자 자료를 보존했다. 이번 요청에는 커밋/푸시를 포함하지 않는다.

UI 테스트 업로드 2건(`업로드 UI 검증용`, `업로드 UI 검증용 수정`)은 보관함에 남겨 두었다. 이름/설명 기준 삭제는 자동 승인 검토에서 사용자 자료와 충돌 가능성을 이유로 거절되어 실행하지 않았다.
