# ASA157 — 개인 자동화 분류

- 사용자는 내 자동화에서 카테고리 추가·이름 변경·순서 변경·삭제를 할 수 있다.
- 카드 전체 드래그 또는 오른쪽 위 메뉴로 분류하고 이름 검색/카테고리 필터를 함께 사용한다. 버튼은 드래그를 시작하지 않는다.
- 카테고리 삭제 시 자동화는 미분류로 돌아가고 실행 정의·예약·기록은 보존한다.
- 인증된 사용자 본인의 workspace_id + user_id로 저장한다. 관리자 전용 에이전트 카테고리와 별도이다.
- 변경은 즉시 저장하며 revision 충돌 시 최신 분류를 다시 불러온다.

## 검증

- 전체 pytest 253 통과. 신규 DB 통합 테스트 2개: 일반 member 관리, 인증/CSRF, 사용자·workspace 격리, stale revision, 잘못된 자동화 ID, 중복 카테고리 이름, 삭제 후 정의·예약·실행 이력 동일성.
- src ruff, mypy 48 파일, frontend typecheck/build 통과. 테스트 폴더의 기존 ruff 오류 71건은 별도 잔여 사항.
- 실제 로컬 브라우저: 검색 한 건 필터링, 미분류 필터, 카드 메뉴 및 Escape 닫기, 기존 실행 입력/예약/기록 화면 확인.
- 실제 포인터 드래그앤드롭과 모바일 실기기 검증은 수행하지 않았다. 사용자 자동화/예약을 임의로 변경하거나 유료 AI를 실행하지 않았다.
- 로컬 migration 적용과 API 재시작 완료.

## ASA158 — 선택 기능으로 변경
- 기본 검색/평면 목록. 공통 스위치 카테고리로 정리를 켜야 필터·관리·드래그·메뉴를 노출한다.
- 사용자별 enabled 저장, 기본 false, 끄기/켜기 시 카테고리와 소속 보존.
- DB 회귀 테스트에 false→true→false→true 및 사용자 격리/분류 보존 추가. 전체253통과114.51초, src ruff/mypy48/typecheck/build 통과.
- 브라우저 켜기, 새로고침 후 true, 끄기 후 false/카드9/필터0/메뉴0 확인. 최종 기본 꺼짐 상태로 복원. 모바일 실기기 미검증.

## ASA159 — 커밋 전 반응형 검증
- Chrome CSS viewport400px 다크, 320px 밝은 테마에서 스위치 켜기·끄기, 이름 검색, 미분류 필터, 카드 메뉴 열기/Escape 닫기 확인.
- 400px: document scrollWidth381, 메뉴 x112.64~332.64px. 320px: scrollWidth301, 메뉴 x32.64~252.64px. 가로 넘침 없음. 카드 하단 실행/예약/기록 버튼은 한 행에서 겹치지 않음.
- 테마 토큰 반영 및 메뉴 영역 DOM 경계 확인. 캡처 API Page.captureScreenshot이 반복 timeout으로 새 스크린샷 시각 검증은 미완료. 모바일 실기기/터치 드래그도 미검증.
- 검증 후 분류 꺼짐/다크 테마 복원, viewport override reset. 사용자 분류·예약·생성 결과 변경 없음.
- 커밋 범위는 ASA157~158 코드/테스트/문서. 사용자 자료·생성 자산·.env·.local·.next·.venv 제외, 파일 삭제 없음.
