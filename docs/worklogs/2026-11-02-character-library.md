# ASA-163 이미지 카드 보관함과 씬 입력 연결

- 캐릭터별 확정 이미지(없으면 최신 성공 이미지)를 카드로 표시. 작업·원본 에이전트·버전·상태, 검색/작업/에이전트/상태 필터, 24개 페이지 제공.
- 상세에서 크게 보기, 이전 버전과 당시 설정 확인, 원래 실행으로 이동.
- 씬 입력에서 보관함의 확정 이미지 선택. 서버가 설정을 구성하고 실행 직전 확정/사용 제외/workspace/위조 여부 재검증. 기존 전체 프로젝트 handoff 유지.
- 로컬 씬 이미지 에이전트의 characters 입력 계약만 확장. 지침 및 다른 에이전트 변경 없음.
- 사용자 이미지·작업·대본·씬 원문 보존. AI 유료 호출 0회.

검증:
- 전체 backend pytest 261 passed (92.62s). 이후 기존/새 선택 형식 큐 경로 2 passed (기존 테스트를 두 형식으로 확장).
- backend src ruff/mypy 통과. 전체 tests lint의 기존 오류는 이번 범위 밖.
- frontend typecheck 통과, production build 통과 (최초 sandbox EPERM 후 권한 재실행).
- 실제 로컬 자료: 대본 2581자, 씬 4206자, 선택 이미지 2장+설정이 모델 직전까지 그대로 전달됨. 캡처 모델 사용, 유료 호출 없음.
- Chrome 실제 화면: 밝은/어두운 보관함, 이름 검색, 상태 필터, 구름 할머니 v2→v1 전환, 이하나/할머니 2장 선택 반영, 모바일 선택창 재열기/취소 후 기존 선택 유지 확인. 모바일 390×844 확인 후 viewport 복구.
- API/대본 워커 로컬 재시작. 워커는 유휴 잠금과 실행 중 요청 0건 확인 후 재시작.

제한: 아직 이미지가 없는 캐릭터는 원래 작업에서 확인. 보관함은 생성된 이미지를 보여줌. 실 공급자 유료 생성은 이번 UI/전달 검증에서 수행하지 않음.
