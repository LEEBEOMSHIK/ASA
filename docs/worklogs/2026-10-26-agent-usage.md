# ASA-017 사용 위치 안내와 도구 접기

3번 전체를 native details/summary로 바꾸어 기본 접힘, 선택 개수 표시, 선택 상태 보존을 제공한다.
2번은 항상 지킬 지침과 매번 바뀌는 입력의 차이를 먼저 설명한다.
지금 양식 정의 → 나중 실행 시 실제 값 입력 → 결과 확인/후속 자동화 연결 순서로 사용 위치를 안내한다.
현재 스키마 설명을 반영하는 입력/결과 양식 미리보기를 제공하며 실제 실행 UI가 아님을 표시한다.
기존 역할별 고정 예시는 추가 설명으로 접어 둔다.

검증: pytest29개·ruff·mypy17개 소스·웹 typecheck/build 통과.
브라우저 기본 접힘과 2개 선택 표시, 클릭 펼치기 후 기존 선택 유지, Enter로 접기 확인.
실제 실행·자동화 연결·유료 호출 없음. 기존 초안 데이터 변경 없이 UI 확인. 커밋·push 없음.
