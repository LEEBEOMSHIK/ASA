# 작업 공간 새로고침 복원

- 원인: 최근 작업 선택/생성 완료/에이전트 선택이 React state만 갱신했다. 기존 request 초기복원 코드는 있지만 URL을 작성하지 않았고 agent 파라미터는 초기화 직후 삭제했다.
- request(저장된 작업), agent(새 작업 에이전트), repeat(원본 입력으로 다시 작업)를 URL에 보존한다. 상호배타적으로 변경하며 새 작업은 제거한다. pushState/popstate로 뒤로/앞으로 탐색을 연결한다.
- 인증/도구 목록 로드 후 URL을 복원하므로 로딩 도중 뒤로 가기도 반영된다. 비동기 원본 조회의 정리/순서 토큰으로 늦은 응답이 다른 화면을 덮지 않도록 한다. 권한은 기존 API 검증을 사용한다.
- 새로고침은 저장된 자료와 선택한 작업/에이전트만 복원한다. 미저장 초안·스크롤·캐릭터 내부 선택·펼침 상태의 영속화는 추가하지 않았다. URL에 입력본문/비밀값을 저장하지 않는다. 복원 시 AI 생성/저장을 실행하지 않는다.
