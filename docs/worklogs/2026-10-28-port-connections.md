# ASA-045 연결점 중심 자동화 빌더

사용자 승인: 큰 다음 블록 연결 버튼을 입력/출력 연결점으로 교체한다. 출력 드래그→입력 드롭 및 클릭→클릭, 빈 캔버스 드롭→블록 선택 후 자동 연결, 선 선택→변경/삭제, 상세 연결 관리는 접힌 상태로 제공한다.

구현 순서: 연결점/노드 치수 공통화 → pointer capture 기반 드래그와 취소 → 입력 대상 강조 및 연결 교체 → 새 블록 선택 메뉴 → 연결 관리 접기/선 도구 → 경로/전체 검사 및 브라우저 검증.

제약: 기존 그래프 데이터 형식은 유지한다. 자기 연결/시작으로 돌아가기 금지와 50블록/100선 한도를 UI에서도 확인한다. 복잡한 분기·반복의 실행 유효성은 기존 서버 검증이 최종 판단한다. 임시 연결은 저장하지 않으며 취소는 기존 선을 보존한다. 선이 여러 개 들어오는 블록은 기존 합류 진입점 분산을 유지하고 각 진입점에 점을 표시한다.

## 검증 결과
- 큰 다음 블록 연결 버튼을 12px 시각 연결점/44px 조작 영역으로 교체. 일반 블록90px, 분기/반복166px. 선과 연결점 좌표 일치, 합류점 분산 유지.
- 클릭→클릭 연결 교체, 출력→입력 실제 드래그, 빈 공간 드롭→조건 블록 생성+자동 연결, Esc 취소(기존 선 유지), Enter 키 연결, 합류 2선, 선 선택→해당 선만 삭제, 좌표 편집 및 접힌 연결 관리 확인.
- 첫 드래그 검증에서 연결 안내 높이 변경으로 도착점이 움직이는 결함을 발견해 64px 고정 영역으로 수정한 후 재검증 성공.
- desktop1440x1000 및 원래 좁은 화면에서 확인. 임시 viewport 복원. 저장하지 않은 테스트 초안만 변경, 기존 저장 자동화 수정 없음. 스크린샷 `.local/verification/port-connections.png`.
- 경로 테스트19개 통과(새 작은 카드·조건 분기·합류 충돌 검증 포함), backend pytest123·ruff·mypy28, frontend typecheck/build 통과.
- 자동화 실행 순서/데이터 형식 변경 없음. 복잡한 전체 그래프 실행 유효성은 서버 검증을 사용한다. 모바일 실제 터치 하드웨어 검증은 미실시. 유료 호출/배포/커밋/push 없음.
