# 씬 시간 배분 확인

- timing 설정인 작업은 기존 대사별 음성 카드 대신 시간 요약, 화자별 공통 축 타임라인, 간격 목록, 단일 전체 플레이어를 표시. production 검토는 유지.
- 시간은 실제 WAV 길이 기준. 구간 합집합으로 여백/겹침 계산, 유효한 cue별 최신 음성만 사용. 누락/중첩이면 preview차단, 초과면 표시하고 원본을 자르지 않음. 명시목표 없으면 배정구간 기준이라고 표시.
- 인증 및 workspace/버전 계보를 유지하는 GET timing-preview. 기존 PCM을 실제 시작 시점에 놓고 시작/사이/끝에 무음 삽입. 원본 파일과 답변/확정이력은 보존, 외부 API 호출 없음. 기존 이루리 측정 설정에 이미 정정된30초 목표를 명시(파일/답변 변경 없음).
- 실제 Chrome1600px 양테마: 목표30/전체30/음성16.5/여백13.5, 음성8개·오류1제외, 개별플레이어0/전체플레이어1. 30초 끝까지 재생 ended=true/error없음 확인. 재생·무음 배치를 검증했고 청각적 연기 품질은 평가하지 않음.
- 요약 dd top535.63px동일, 타임라인3행 x458.77/width1005.80px동일, 섹션gap16px. 기존 사이드바 폭 유지. CSS433px 요약2열135.24px, 타임라인3행286.48px동일, 문서가로넘침없음. 모바일캡처timeout으로 시각검증 미완료. 오류·누락·중첩은 테스트로 검증하고 사용자자료로 강제로 만들지 않음.
- 증거 `.local/diagnostics/timing-preview/{summary-dark,dark,light}.png`. 테마/viewport복원 및 기존작업v3보존.
- 자동TTS는 추가하지 않았다. 씬 에이전트 요청만으로 음성은 생성되지 않으며 기존 측정 음성이 준비된 작업에 이번 UI가 표시된다. 새 유료호출/커밋/푸시 없음.
