# ASA-018 그룹별 접기와 실행 화면 체험

이전 ASA-017의 ‘3번 전체 접기’ 해석을 사용자 정정에 따라 취소했다.
3번은 일반 영역이며 ASA 기본 도구/내가 만든 에이전트에 각각 native details를 적용했다.
독립 열기/닫기, 선택 개수 및 선택 상태 유지. 초기에는 두 그룹 모두 접힌다.

2번의 설명용 양식 대신 현재 초안으로 구성한 별도 실행 화면 미리보기 버튼을 제공한다.
입력란은 텍스트/숫자/예·아니오/복합 JSON에 맞추고 결과 영역은 빈 결과 자리로 표시한다.
입력 확인은 브라우저에서만 수행한다. 전체 스키마 검증·AI 실행은 아니며 서버 전송/저장하지 않는다.
편집 화면 복귀 시 체험 입력은 삭제되지만 원래 에이전트 초안은 유지된다.
화면 전환 시 제목으로 포커스, 복귀 시 진입 버튼으로 포커스를 복원한다.

검증: pytest29개, ruff/mypy17개 소스, 웹 typecheck/build 통과. 포커스 수정 후 웹 검사 재통과.
브라우저에서 ASA만 열기→내 에이전트 열기→ASA만 키보드로 닫기, 선택 유지 확인.
실행 화면에서 텍스트 입력→입력 확인→빈 결과 안내→편집 복귀 및 포커스 복원 확인.
복합 입력의 모든 제약 및 모바일 화면은 이번 브라우저 검사에서 검증하지 않았다.
실제 AI 호출·유료 비용·커밋·push 없음.
