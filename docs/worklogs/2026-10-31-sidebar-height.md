# ASA-102 최근 작업 영역 높이 복구

원인: 스튜디오 메뉴에 높이 제한이 없고 최근 작업 flex item의 min-height가 0이어서, 관리자 메뉴가 늘거나 화면 높이가 줄면 목록이 축소됨. 사이드바 접기 버튼 외에 콘텐츠가 height:100%를 사용해 전체 높이도 초과할 수 있었음.

변경:
- 사이드바를 세로 flex로 구성하고 콘텐츠는 접기 버튼을 제외한 남은 높이를 사용.
- 스튜디오 메뉴는 최대32dvh에서 독립 스크롤.
- 최근 작업은 공통 토큰 --sidebar-recent-min-height(180px)을 확보하고 제목을 sticky로 유지.
- 극단적으로 짧은 화면에는 콘텐츠 전체 스크롤 허용. 모바일 기존 메뉴 방식 유지.
- 브라우저 확대·OS 배율·글자 크기는 변경하지 않음.

실제 브라우저 확인:
- 최근 작업 첫 항목이 보이며 캐릭터 설정 요청을 클릭해 상세 진입 성공.
- 스튜디오 메뉴를 아래로 스크롤해 관리자 메뉴 접근 가능, 최근 작업 영역 유지.
- 최근 작업만 스크롤해 오래된 요청 접근 가능, 제목 유지.
- 사용자 첨부 화면 당시의 브라우저 확대율은 확인하지 못했으므로 확대가 발생한 원인은 단정하지 않음.
