# ASA-080 실제 AI 수정 요청 검증

사용자 승인에 따라 고객 화면에서 실제 수정 요청 1회 실행. 모델 gpt-6.1-terra.

- 원래 요청: b05622eb-8c37-49a8-b79d-403f1d9d4ae5
- 수정 실행: a27b08c8-7ed8-4e64-ba4c-685599e68040
- 사용량 이벤트: 492b885f-3150-4ada-bea0-11ac36cb8351
- 기준 대본1 → 결과 대본2, 등록 에이전트 버전3 유지.
- 호출 전 v1과 호출 후 v1이 완전히 일치. 큐 프롬프트 previous_script와 공급자 전달 메시지에 기존 대본 포함 확인.
- 기존 제목·첫 문장·핵심을 유지하고 세 문장으로 줄인 결과, 지정 마무리 문장 반영. 고객 결과와 v2 일치.
- 입력1221/출력107, 캐시읽기0/생성1219. 호출 처리시간3946ms. 예상USD0.00206075, cost_state estimated. 동일 실행 이벤트1건으로 중복 없음.
- 저장 요율 기준 검산: (일반입력2 × 1 + 캐시생성1219 × 1.25 + 출력107 × 5) / 1000000 = 0.00206075. 실제 청구 확정액은 아님.
- 브라우저 자동 v2 표시·이전 대본 비교·관리자 호출 행 및 원래 요청/실행ID 추적 확인.
- 증거: .local/verification/revision-v2.png, revision-usage.png (Git 제외).
- 코드 변경 없는 실제 기능 검증이므로 전체 단위 테스트/빌드는 재실행하지 않음. 이번 검증은 단일 수정 사례이며 모든 문체/제약 준수를 보장하지 않음.
