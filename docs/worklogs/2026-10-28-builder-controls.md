# ASA-041 메뉴/블록 편집 개선

## 변경
공통 SidebarToggle/useSidebarCollapse로 고객/관리 GNB 접기·열기를 제공하고 브라우저에 상태를 저장한다. 모바일 메뉴는 유지한다. 블록에 명시적인 설정 버튼, 설정 패널 상단에 이름/연결 개수/삭제를 제공한다. 작은 화면의 설정 패널은 우측 고정 패널로 표시한다. 삭제 시 해당 블록과 incident edge를 제거하며 다음 편집 전까지 전체 삭제 상태를 되돌릴 수 있다. 시작과 단일 최종 결과 삭제는 보호한다. 새 블록 추가 시 테스트 패널을 닫고 설정을 보여준다.
