# ASA-019 자유 답변 기본값

신규 에이전트와 세 가지 시작 예시는 output_schema.type=string을 기본으로 한다.
‘항목별로 받기’를 고르면 object 스키마 편집을 제공한다. 기존 초안·버전은 자동 변경하지 않는다.
편집 중 방식을 왕복하면 각 방식의 편집값을 메모리에 보존한다. 재로드 후에는 저장된 활성 방식만 남는다.
서버는 입력 object를 유지하고 출력에 string/object를 허용하며 게시 시 기존 길이 상한을 적용한다.
향후 실행기는 string 결과를 자유 텍스트 응답으로, object 결과를 구조화 출력으로 처리해야 한다.

실행 화면은 실제 실행 전 결과 항목·추정 내용·입력 확인 내역을 결과 영역에 표시하지 않는다.
입력 확인 내역은 입력 영역에만 표시하고 결과에는 빈 자리 안내만 남긴다.

검증: 자유 텍스트 출력 단위 테스트의 실패 확인 후 구현. 실제 DB 저장/게시/형식 변경 후
과거 string 버전 유지 회귀 테스트 추가. 전체 pytest31개, ruff/mypy17개 소스, 웹 타입/빌드 통과.
브라우저 신규 기본값, 항목 설명 수정→자유 답변→항목 복원, 입력 확인 후 빈 결과 표시 확인.
검증용 미저장 초안은 정리했으며 기존 사용자 데이터는 수정하지 않았다.
실제 AI 실행·유료 호출·커밋·push 없음.
