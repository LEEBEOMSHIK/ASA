# 씬 시간 측정 자동 연결

새 요청/AI에게 수정 요청의 실행 스냅샷에 after_tasks.scene_timing을 보존한다.
모델 본문 출력 계약은 유지하고 별도 timing_plan으로 화자·발화·시각을 받는다.
계약 검증 후 답변과 동일 트랜잭션에 버전별 설정 및 UUID5 음성 작업을 저장한다.
동일 요청 재전송은 중복 음성 작업을 만들지 않는다. 중단·불확실 음성은 자동 재호출하지 않는다.

모든 발화가 정상 생성되면 앞/사이/끝 여백을 유지해 실측 길이로 재배치한다.
전체 길이가 목표를 넘으면 초과량을 표시하며 자르거나 배속하지 않는다. 기존 답변은 그대로다.
화면은 대기/생성 상태를 3초마다 갱신하고 완료 후 시간 요약·타임라인·전체 미리듣기를 제공한다.
최종 음성 확정/합성에서 측정용 음성을 제외하는 기존 정책을 유지한다.

로컬 적용: 씬 구성 에이전트 revision8→9에 설정 추가, .local에 원본 백업.
기존 답변·음성을 변경하거나 새 유료 결과를 만들지 않았다. 음성 대기0/에이전트 대기0을
확인한 뒤 음성 API 활성화, 기존 OpenAI 키 재사용, 유휴 script-worker 정상 중지/재시작 및
audio-worker 시작. 두 워커 running/busy=false 확인. API autoreload로 최신 설정 반영.

시각 검증: 실제 기존 작업 v3의 메타 정보와 비교 버튼 사이 공통 space-4=16px.
1600px 밝음/어둠에서 실측15.998px, 비교 펼침/접힘과 키보드 포커스 확인.
CSS433px에서 동일 간격, 가로 넘침 없음, 전체 플레이어286px 확인.
좁은 화면 screenshot은 브라우저 capture timeout으로 확보하지 못했으므로 DOM 검증만 기록한다.
기존30초 플레이어 metadata 정상. 생성 중/오류 UI는 실제 브라우저 미검증,
새 유료 AI→TTS 생성은 실행하지 않고 mock provider/격리 DB/워커로 검증한다.
증거: .local/diagnostics/auto-scene-timing/{dark-footer,light-footer}.png.
테마·viewport·비교 펼침 상태는 복원했다. 사이드바 폭 변경 없음.

검사 기록은 WORKBOARD.md의 완료 항목을 참조한다.
