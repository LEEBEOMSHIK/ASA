# 작업별 브라우저 임시 입력

- 신규 요청 입력, 기존 답변 편집/AI 재요청 문구·재요청 입력, 음성 설정에 공통 useWorkDraft를 연결했다. 서버 정식 저장/AI 실행과 분리한다.
- 키: workspace+사용자+화면 종류+작업ID/임시draft UUID+답변/에이전트/음성 revision. `/session`에 principal.user_id만 추가한다. 토큰/키는 저장하지 않는다. URL에는 본문 없이 식별자만 둔다.
- 같은 에이전트를 새로 선택할 때 별도 draft UUID를 부여한다. refresh와 해당 URL 재방문은 같은 초안, 새 작업은 다른 초안이다. 기존 답변 버전 선택은 answer URL로 유지한다. 현재 버전과 다른 초안을 자동 덮어쓰지 않는다.
- localStorage에 입력 변경을 저장하고 다음 진입에 복원 안내한다. 30일 만료. 브라우저 저장 차단/손상/용량 부족은 안내하고 정식 저장됨으로 표시하지 않는다. 정상 저장·생성 접수 성공 후 해당 초안을 정리하고 실패하면 유지한다. 신규/음성 설정은 임시 입력 지우기로 원래 값으로 복귀한다.
- 이 브라우저의 임시저장이다. 기기간 동기화·원본 파일 업로드 재개는 제공하지 않는다. 완료된 자산 참조는 보존하며 진행 중 파일은 다시 선택해야 한다. 개별 이미지 생성 팝업 등 다른 도구의 편집은 이번 범위가 아니다.
- 실브라우저: 신규 캐릭터 입력 A 작성→reload 복원, 같은 에이전트 신규 B는 빈 입력/다른UUID, A URL 재방문 복원 확인. 기존 캐릭터 작업 재요청 문구 reload 복원, 나레이션 언어 초안 reload 복원 확인. 테스트 문구/음성 초안은 정리했고 원래 한국어/세이지 설정 유지. 제출/AI호출/사용자 정식 저장 없음.
- 증거 `.local/diagnostics/input-draft-restored.png`. dark1600 기존 배너/버튼 스타일 사용. 밝은/좁은 화면, 실제 답변 저장·생성 성공 후 제거, 저장 공간 초과, 사용자 변경 및 다른 버전 실브라우저는 미검증.
