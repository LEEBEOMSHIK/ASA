# 기존 작업 재요청의 최신 지침 적용

2026-11-09. 사용자가 기존 작업에서도 최신 에이전트 지침으로 다시 요청하도록 승인했다.

`AI에게 수정 요청`의 신규 실행은 최신 저장 설정을 사용한다. 최초 접수, 같은 시도의 재전송, 이미 대기/실행 중인 시도는 당시 설정을 유지한다. 이전 답변과 최초 입력을 보존하고, 새 답변에 적용한 지침 버전을 따로 표시한다. 최신 입력 계약이 달라진 경우 같은 작업 안에서 입력을 보완할 수 있다. 별도 새 작업을 여는 `이 요청으로 다시 작업`은 이번 변경 범위 밖이다.

검증: 전체 pytest457건과 추가 모델·멱등 회귀를 포함한 전용3건 통과, Ruff/mypy82 통과. frontend 입력 변환 테스트2건/typecheck/build 통과. 유료 호출 없이 fake generator로 실제 전달 프롬프트, 최신 모델, 입력 보완, 과거 답변 스키마, 대기 시도의 설정 고정을 검증했다.

실화면: 이루리와 딸꾹 유령 원본 답변 v1·지침v7과 재요청 최신v8 표시. 입력 편집 열기/취소, 원문 유지, 공통 AgentInput 사용 확인. 데스크톱 밝음/어둠에서 상하단과 포커스 확인, 필드 간격24px·왼쪽 시작점 일치. 좁은 화면 DOM433px에서 가로 넘침 없음. 좁은 화면 캡처 timeout으로 이미지 미검증, 최신 필수 입력 변경 오류 화면은 브라우저에서 사용자 설정을 바꾸지 않아 미검증이다. 테마/viewport 복원, 임시 탭 종료. 증거는 .local/diagnostics/latest-retry에 보관하며 Git 제외.

로컬 migration 적용 및 대기 중인 에이전트 워커 정상 재시작. 원본 대본·씬·이미지·지침 설정은 이번 검증에서 저장하지 않았다. 커밋/푸시는 하지 않았다.
