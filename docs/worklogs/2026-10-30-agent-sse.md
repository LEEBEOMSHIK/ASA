# ASA-095 · 에이전트 SSE 진행 안내

## 구현
- 고객 요청 상세와 최근 작업을 인증된 SSE 스냅샷 구독으로 전환. 모델 공개용 요청 이해/작성 방향/부분 답변을 한 호출에서 순서대로 생성. 내부 사고 과정은 노출하지 않음.
- 부분 출력은 workspace/request/attempt 경계로 저장(250ms 제한). API는500ms 주기로 DB 변경을 확인해 SSE 전달. 브라우저 재연결은 최신 스냅샷을 복원하며 실행 접수/외부 호출을 수행하지 않음. 세션 재검증, 연결 종료 처리,45초 수명 및 keepalive 적용.
- 최종 출력 계약 검증 후 value만 답변 버전 저장. 실패 시 부분 출력은 미완성으로 유지. 기존 답변 보존. 원문 오류/자격 증명 스트리밍 없음.
- 최근 작업은 SSE로 신규 요청/상태를 갱신하고 다른 작업을 보아도 작성중/완료 반영. 요청 상세 헤더도 같은 업데이트 사용.
- SSE gzip 버퍼링을 실제 프록시에서 발견: 직접API 첫프레임1.23초, Next 프록시46.91초. identity/no-transform 설정 후 웹 경유 첫 스냅샷1.07초 확인.
