# ASA-040 전체 연결 자동 분리

## 변경
이전 선택 강조만으로는 전체 흐름 파악이 어려웠다. 전체 연결의 경로를 함께 계산하고 이미 사용된 평행 구간과 12px 간격을 확보한다. 같은 블록으로 들어가는 선은 진입 높이를 분산한다. 연결 정렬은 출발 블록 위치/포트/ID에 의존하여 입력 배열 순서를 바꿔도 동일한 결과를 낸다. 둥근 모서리 반경은 6px 이내로 유지하고 A* 탐색에 회전 비용을 부여했다.

드래그 중에는 기존 스냅샷을 사용하고 놓으면 전체 경로를 다시 계산한다. 이동 중 임시 선도 분산 진입 높이를 유지한다. 공간 부족은 crowded로 표시하고 경고와 기존 안전 경로를 제공한다. 임의로 연결이나 블록 좌표를 바꾸지 않는다.

## 검증
- 경로 테스트 18개 통과. 새 테스트는 10블록12선 분기/반복/합류의 공유 구간 없음, 진입점 분산, 입력 배열 역순 결정성, 혼잡 상태와 연결 보존, 50블록98선 상한을 검사한다.
- 50블록98선: 블록 관통/공유 직선 구간/혼잡 경로 0건. 최종 로컬 계산 진단 515.4ms(프레임 시간 보장 아님).
- 실제 브라우저: 선택 강조 없는 12개 연결의 SVG 직선 구간48개에서 공유 구간0건 확인. 배치 간격 경고 없음, 초안은 저장됨 유지.
- 화면 `.local/verification/graph-separated-lanes.png` (Git 제외).

## 한계
평행한 공유 구간 분리와 교차점 제거는 다르다. 수직으로 가로지르는 교차는 남을 수 있다. 공간이 매우 좁거나 진입점이 과밀한 임의 배치의 무겹침을 보장하지 않는다. 이 경우 경고한다. 최대 크기에서 계산 시간이 발생하므로 드래그 매 프레임 전체 계산은 하지 않는다. 외부 AI 호출/외부 게시/운영 부하 검증은 없음.
