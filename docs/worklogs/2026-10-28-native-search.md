# ASA-044 내장 웹 검색 연결 — 2026-10-28

OpenAI/Claude 직접 AI 요청에 웹 검색 옵션 추가. 공급자 변경 시 옵션 초기화, 검색 중 글 출력 계약, 검색 지원 모델 표시/허용 목록 검증, 공급자 키 분리 유지. OpenAI Responses web_search(max_tool_calls=1/store=false), Claude basic web_search_20250305(max_uses=1)을 LangChain으로 호출한다. 추가 임의 도구/코드 실행/외부 검색 서비스 가입은 필요하지 않다.

답변의 출처 위치를 링크로 보존하고 결과/샘플 화면에 안전한 HTTP(S) 앵커로 표시한다. 검색 미사용 상태를 명시한다. 불완전 응답·pause_turn·서버 검색 오류는 기존 needs_attention 처리로 중단하고 자동 재시도하지 않는다. 공급자별 서버 허용 모델 목록은 운영자가 확인/설정해야 한다.

검증:
- 전체 pytest 123개 통과(2026-10-28), ruff 통과, mypy 28파일 통과.
- 설치된 실제 LangChain + OpenAI/Anthropic SDK를 HTTP 모의 전송으로 호출: 요청 도구명/상한/모델/store옵션 및 실제 응답 메타데이터→출처 링크 변환 검증. Anthropic SDK는 httpx2를 사용하므로 테스트 전송도 이에 맞췄다.
- 두 공급자의 DB 실행/결과 저장/승인 후 재개 시 호출1회 유지 검증.
- 모델 제거·지원 설정 해제·목록 출력 차단·위험 URL·중단 응답·검색 오류·검색 미사용 테스트.
- frontend typecheck/build 통과. 최종 검색 지원 모델 표시 변경 후 재실행.
- 브라우저 도구 browser.user 오류로 현재 화면 클릭 검증 미완료. 이전 스크린샷을 새 화면 증거로 사용하지 않았다.
- 실제 유료 호출0회, API 키/실사용 모델 환경 미변경. 예약 타이머를 통한 실제 검색 및 공급자 실계정 동작은 미검증. 검색료와 모델료는 별도이며 무료를 보장하지 않는다.
