# ASA-015 에이전트 UX — 2026-10-26

사용자 요청: 올드한 시각 구성과 이해하기 어려운 에이전트 상세 편집 개선.
사용자 선택: 밝고 정돈된 작업 도구 스타일.

공통 light 토큰·표면·버튼·텍스트 계층·여백을 정리해 로그인/목록/도구/편집에 적용했다.
새 에이전트에는 대본 작가·아이디어 기획자·검수자 예시를 제공한다.
역할→정보와 결과→선택 도구 순서로 편집하고 스키마 설명을 한국어로 입력한다.
키·자료형·모델·실행 한도는 접힌 세부 설정으로 이동했다. 기존 스키마 키는 자동 변경하지 않는다.
설정 요약, 저장/등록 차이, 등록의 작업 공간 내부 범위를 설명한다.
등록 시 서버 검증을 그대로 사용하며 AI 실행·출력 결과를 가장하지 않는다.

실제 검증: 전체 pytest29개·ruff/mypy17개 소스·frontend typecheck/build 통과.
브라우저에서 예시 선택→한국어 설명 수정→초안 저장→도구 등록 성공 확인.
‘샘플 · 쉬운 대본 작가’는 확인용으로 로컬에 보관하며 실제 AI 실행 결과가 아니다.
360/768px에서 document 폭과 content 폭이 같음을 확인했고 360px 화면과 기본 데스크톱 화면을 시각 확인했다.
키보드 Tab으로 이름→한 줄 소개 이동과 포커스 표시를 확인했다.
전체 스크린리더·모든 오류 상태·모든 장치 검증은 수행하지 않았다.
API 계약/이전 버전 불변성 회귀는 기존 실제 DB 테스트로 확인했다.
유료 호출·커밋·push 없음.
