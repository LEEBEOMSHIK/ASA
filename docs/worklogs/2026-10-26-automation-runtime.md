# ASA-033 자동화 실행·예약 (2026-10-26)

## 구현
- 카드 편집/실행/시간 예약/기록 진입, 요청과 단계별 결과 분리, 결과 항목을 읽기 쉽게 표시.
- workspace 범위 DB 실행 스냅샷, 순차 LangGraph 워커, LangChain 외부 모델 어댑터.
- 단계별 확인 대기/이어가기(확인 대상 단계 비교), 대기 취소, 최근50개 이력/새 작업 준비.
- 1회/매일 한국 시간 예약, 구성 버전 고정, 누락 예약 한 번으로 합침, 진행 중이면 건너뜀.
- workspace 실행 잠금, 외부 호출 의도 선저장, 중단/불확실 결과 자동 재시도 금지, 예약 일시중지.
- 기본 AI 비활성, 최근24시간 호출수/응답토큰 상한. 비밀값은 실행 manifest에 저장하지 않음.

## 실제 검증
- pytest 최종50개 통과(실제 로컬 PostgreSQL의 격리 테스트 스키마).
- ruff 통과, mypy24개 소스 통과, 프런트엔드 typecheck 및 최종 production build 통과.
- 수동 실행 멱등/버전고정/CSRF/다른 workspace 차단, 예약 중복/누락/진행 중 건너뜀,
  오래된 단계 승인 거부, 동시 워커, 강제 중단 상태 복구, 호출한도/응답실패 검증.
- AI→도구 전달은 모의 생성기를 사용: 고양이 대본6자 전달/계산, 외부 AI0회.
- 리뷰 지적3개 수정: 승인 대상 단계 고정, 예약에도 대기열100개 적용, 1회 예약 시각 재표시.
- 실제 브라우저: 체험용 글자 수 자동화에서 ‘상자를 좋아하는 고양이’12자 계산,
  결과 확인 대기→승인→완료, 이력에서 결과 재조회. 매일 예약 저장/다음 시각 표시/예약 끄기.
- 360/768px 실행 화면 가로 넘침 없음, 카드 밝게/어둡게 확인.
- 체험용 자동화와 완료 실행1건을 로컬 DB에 보존. 검증 예약은 꺼둠.
- 로컬 DB 마이그레이션 적용. automation-worker는 AI 비활성 설정으로 실행 중.
- 스크린샷 .local/verification/asa033-run.png, asa033-cards.png (Git 제외).

## 미검증·제한
- 실제 유료 API, 공급자별 모델의 구조화 출력 호환성/품질/실사용 비용은 검증하지 않음.
- 1회 예약은 API/DB 테스트 통과. 브라우저 자동화에서 datetime-local 입력 이벤트를
  안정적으로 확정하지 못해 1회 예약의 화면 제출은 미검증. 날짜 재표시 수정은 소스 검토.
- 중첩 에이전트 도구 호출, 금액예산/실측사용량 UI, 이미지/영상, 분기/병렬,
  실행 결과 수정 후 선택 단계 재실행은 후속. 현재 단계 확인은 승인/취소만 제공.
- API/DB 사이 exactly-once 보장하지 않음. 로컬PC·DB·워커가 켜져 있어야 시간 예약 처리.
- 고객 대본 버전관리와 자동화 실행 기록은 아직 별도. 커밋/push/배포 없음.
