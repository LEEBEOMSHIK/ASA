# ASA-029 고객 대본 단계

고객 작업 상세에 제작 단계 안내와 대본 편집·버전 선택·이전 버전 비교·확정을 추가했다.
AI 첫 작성 및 재작성 요청은 기준 버전과 수정 지시를 보존하며 대본만 대상으로 한다.
직접 작성/AI 작성 출처, 실행 대기/실행 중/결과 확인 필요/취소 상태를 구분한다.
수정 중 탐색 경고, 충돌 시 입력 보존, 대기 요청 취소를 제공한다.

## 검증

- scripts/check.ps1: pytest 37개, ruff, mypy(21개 소스), frontend typecheck/build 통과.
- 격리 DB 테스트: 버전 보존·확정 해제·멱등 실행·수정 충돌·실패 시 원본 보존·workspace 경계·CSRF.
- 실제 로컬 DB migration 적용.
- 브라우저: 별도 검증용 요청 생성, 직접 v1 저장/확정, v2 수정 후 검토 상태, 이전 대본 비교,
  AI 재작성 요청 대기/취소, v2 확정 확인. 360px 화면 가로 넘침 없음.
- 검증용 샘플 요청 1건과 직접 작성 대본 2개는 로컬 DB에 보존. 대기 요청은 취소했다.

## 미검증 및 남은 범위

실제 모델 설정·유료 API 호출·실제 영상 생성은 하지 않았다. 테스트 생성기는 주입한 가짜 응답이다.
AI 실행은 명시 실행 로컬 CLI이며 상시 소비자·자동 복구·비용 원장·SaaS 인증은 미구현이다.
도구 연결 에이전트 실행과 후속 미디어 단계는 미지원. 기존 요청 전체 완료 상태와 대본 확정은 구분한다.
외부 호출 도중 워커 종료 시 자동 재실행하지 않으며 운영자가 공급자 결과와 DB를 대조해야 한다.
커밋·push·외부 배포 없음.
