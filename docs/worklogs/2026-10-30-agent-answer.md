# ASA-076 단독 에이전트 요청·답변 화면

사용자 확정: 단독 실행은 선택한 에이전트의 역할과 답변만 제공한다. 자동화 단계/연결은 사용자가 구성한다.

## 변경
- 고객 작업 상세에서 고정 쇼츠 제작 6단계와 제작 안내 제거.
- 내 요청을 답변보다 먼저 표시하고 중복 JSON 결과 카드 제거.
- 기존 대본 결과를 제목/대본으로 읽기 표시. 직접 수정을 누를 때만 입력 폼 표시.
- 복사, 수정 취소, 버전 보존, 미저장 보호 유지. AI 수정 요청과 요청 이력은 펼침 상세로 정리.
- 사용자 확정/다음 제작 단계로 오해하게 하는 확정 동작은 고객 화면에서 제거. 기존 저장 데이터/API는 유지.
- 성공 상태를 답변 완료로 명확화. 공통 컴포넌트와 디자인 토큰 사용.

## 검증
기존 실제 AI 성공 요청으로 브라우저에서 읽기 표시, 제작 단계/JSON 중복 제거, 직접 수정, 임시 변경의 미저장 보호, 수정 취소 원문 복원, AI 수정 요청 펼침 확인. 새 AI 호출과 데이터 저장은 수행하지 않았다.
스크린샷: .local/verification/agent-answer-readable.png (Git 제외).

범위: 고객 화면 개선이며, 현재 backend의 제목/내레이션 대본 출력 계약은 유지한다. 범용 출력 계약/새 도구 실행은 이번 변경에 포함하지 않는다. 테스트 취소 이력도 삭제하지 않았다.
