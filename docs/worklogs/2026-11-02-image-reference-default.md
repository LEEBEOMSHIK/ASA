# ASA-166: 추가 지침이 없는 캐릭터 이미지 참조

- 업로드 시 빈 `image_prompt`를 외형 설명으로 대체하지 않고 공란으로 보존한다.
- 입력 이름을 ‘이미지 활용 시 유지할 특징’으로 바꾸고, 공란이면 첨부 이미지의 외형·의상·화풍을 기준으로 삼는다고 안내한다.
- 씬 이미지 템플릿과 로컬 에이전트 지침에 이미지 우선 기본 규칙을 추가했다. 명시한 변경만 적용하고, 불명확한 충돌은 확인 대상으로 표시한다. 씬 구도와 영상 움직임 지침을 구분한다.
- 로컬 에이전트의 기존 사용자 지침 7,999자를 보존해 규칙만 덧붙였다. 저장 revision 6, 총 8,520자. 다른 설정은 유지했으며 새 요청에 적용된다. 기존 실행 기록은 변경하지 않았다.
- 지침 한도를 클라이언트/서버 모두 12,000자로 맞췄다. 과거 업로드 데이터의 지침은 임의로 재작성하지 않았다.
- 보관함 버전 조회의 반환 타입 오류를 딕셔너리 목록 반환으로 정리했다.

검증:
- 빈 문자열/공백/명시 지침 업로드의 저장값과 실제 이미지 모델 입력 전달을 통합 테스트로 확인했다. 외부 AI는 모의 처리했다.
- 12,000자 허용 및 초과 거부 테스트 통과.
- backend src ruff/mypy(50파일), frontend typecheck/build 통과. sandbox 빌드 복사 권한 경고는 권한을 갖춘 재실행에서 해소했다.
- 실제 다크 화면에서 변경된 입력 이름과 설명 확인. 이번 문구 변경의 모바일/라이트 화면은 별도로 재검증하지 않았다.
- 유료 이미지 생성 및 결과물의 시각적 일관성 검증은 실행하지 않았다. 이미지 전달/지침 적용은 품질 보장을 뜻하지 않는다.
- 전체 pytest 최종 결과는 WORKBOARD.md에 기록한다.

커밋/푸시는 이번 요청 범위에 포함하지 않는다.
