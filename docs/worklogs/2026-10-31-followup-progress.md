# 후속 작업 진행 상태

## 변경
- 최근 작업의 AI status를 그대로 보존하면서 별도 work_progress로 검토/생성/확정 상태 표시. 기존 SSE snapshot이 실시간 반영한다.
- 공통 상태 계약과 버전별 항목 결정 저장소를 추가. 캐릭터 이미지 adapter를 연결했으며, 다른 매체는 adapter로 추가할 수 있다.
- 프로젝트를 아직 열지 않은 캐릭터 답변도 최신 answer에서 미생성 항목을 읽는다. 완료는 필요 항목이 1개 이상이며 모두 확정일 때만. 전체 제외는 대상 없음.
- 제외는 이미지·승인 기록을 삭제하지 않으며 복원 가능. 생성 중에는 제외와 확정을 차단한다.
- 새 이미지 요청 시 확정 상태를 재검토로 열고, 이전 버전 유지도 명시적으로 다시 확정 가능. stale tab이 보지 않은 버전을 검토 처리하지 않도록 expected_latest_version 검사.
- 상세 이어서 작업은 해당 답변 버전과 결과 영역으로 이동. 인물별 확인 링크, 축약된 제외 카드/복원 버튼 제공.

## 검증
- 단위 테스트: 비이미지 음성 kind의 공통 집계, 미생성/진행/검토/확정/제외/불명확 결과, 모두 제외.
- DB 통합: 미열람 답변, 재생성, 이전 이미지 재확정, 오래된 탭 거절, 제외/복원, 활성 작업 보호, workspace 격리, 답변 버전 격리.
- 실제 데이터: 검토 필요1/미생성5/확정1. 뭉실이 제외 시 미생성4/제외1로 sidebar SSE 반영 확인, 이후 복원 완료. 생성/수정/확정 유료 호출 없음.
- 실제 브라우저: 최근 작업 클릭, 상세 재개 버튼, 해당 결과 영역 이동, 제외/복원 및 재접속 확인.
- 코드 리뷰에서 stale approval 발견 후 expected_latest_version 검증과 회귀 테스트로 보완.

## 범위
음성·영상 후속 작업 adapter 및 자동화 전체 진행률은 아직 연결하지 않았다. 이번에 만든 공통 계약으로 연결할 수 있으며, 개별 AI 실행에 임의 제작 단계를 강제하지 않는다.
