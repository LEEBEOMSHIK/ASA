# ASA-042 웹 검색·결과 항목 선택

구현: Brave 검색 도구, 서버 전용 환경 설정, 실행 등록 시 설정 검증, graph/legacy 워커 연결, 외부 호출 한도 공유. 결과 항목 선택(map) 블록과 이름·자료형·출처 지정, 스키마 기반 경로 선택, 첫 검색 결과 프리셋, 검색 샘플 채우기. 환경 예시·운영 Compose 전달값·사용 설명 갱신.

검증:
- 새 검색/매핑 테스트 14개 통과: HTTP 모의 응답, 비활성 설정, 오류 숨김, 빈 검색 결과, 타입/이름 검증, 샘플 연결, 체크포인트 JSON 복원.
- 관련 기존 테스트 포함 실행은 39 통과/1 실패. 실패는 기존 LangChain 의존성 uuid_utils DLL에 대한 Windows 응용 프로그램 제어 차단. 이후 추가한 5개는 별도 통과.
- 전체 pytest 실행 시 동일 DLL 문제로 5개 모듈 수집 실패. pytest 플러그인 자동 로딩을 끈 실행도 동일. 보안 설정 변경/우회는 하지 않음.
- ruff 및 mypy(27 소스 파일) 통과.
- frontend typecheck/build 통과, 연결 경로 테스트 18개 통과.
- 브라우저 도구가 기존 ASA 탭의 브라우저에 연결하지 못하여 화면 시각 검증은 미완료.
- 실제 API 호출·유료 호출 없음. DB 워커/예약 실행 및 복구 통합 검증은 DLL 차단 해소 후 필요.

상태 REVIEW: 코드 추가와 독립 테스트 완료, 로컬 전체 실행 검증 보류. 커밋·push 없음.
