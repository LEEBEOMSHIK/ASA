# ASA-100: 에이전트 결과에 캐릭터 이미지 작업 통합

- 실행 결과가 캐릭터 출력 계약이면 JSON 대신 전체 등장인물 목록, 선택 생성, 인물별 이미지 버전/수정/확정 UI를 표시한다.
- `/characters`는 구성 목록과 원본 요청·답변 버전 링크만 제공한다. 별도의 설정 에이전트 실행 폼을 제거했다.
- 생성한 이미지가 있는 인물은 개별 카드에서 수정한다. 선택 생성은 수정한 외형/프롬프트를 사용하고, 접수된 항목은 선택에서 제외한다. 응답 유실 시 동일 payload UUID를 재사용한다.
- source_version 마이그레이션은 기존 프로젝트를 v1에 연결하고 기존 이미지/확정 포인터를 보존한다. 서버는 저장된 불변 답변을 사용한다.
- 이전 버전 링크와 사용자 선택은 SSE 수신 시 유지한다. 새 답변 요청/저장 이후에는 최신 답변을 따른다.

검증:
- backend pytest 186 passed (231.72s), ruff/mypy 통과.
- frontend 32 tests passed, typecheck/build 통과.
- 통합 테스트: 답변 버전별 프로젝트 분리, 중복 import, 다른 workspace 차단, 없는 버전 차단, ID 충돌.
- 기존 테스트: 이미지 생성/편집 시 reference bytes, UUID 중복, 승인 CAS, 워커 중단 보존 및 사용량 기록 (mock, 유료 호출 없음).
- 실제 로컬 브라우저: 기존 답변 7인 목록/워커 연결, 2명 체크 시 버튼 인원 갱신, 이하나 v1/v2 전환 및 수정/확정 UI 확인.
- 새 유료 이미지 생성과 사용자 기준 확정은 실행하지 않음. 기존 이하나 이미지 v1/v2 유지.
