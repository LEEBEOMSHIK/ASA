# 영상 모델에 목소리 특징 전달

- 캐릭터 설정의 기본 음색/샘플 선택 흐름을 설명·언어·속도 의도 입력으로 전환했다. 공통 나레이션은 상단에서 관리하고 저장 후 접힌다.
- 기존 voice 필드/샘플 ID/생성 음성을 삭제하지 않는다. 신규 부분 저장 API는 설명과 사용 여부만 갱신한다. 씬 시간 측정 TTS는 유지한다.
- 비디오 요청에서 선택된 캐릭터 소스 ID를 workspace 내에서 해석하고 그 시점의 특징을 snapshot으로 보관한다. 재요청은 새 snapshot, 답변 수동 편집은 원래 snapshot을 상속한다.
- 실제 영상 요청에는 클립 상대 시간/화자/원문/감정/특징이 전달된다. 모델 오디오 지원과 대사 경계를 사전 검증한다.
- 별도 검토에서 발견된 화자 ID 불일치, 타임라인 범위, 기존 합성 fingerprint 변경, 구버전 나레이션 누락, 답변 편집 스키마, 원본 중복 조회, 재요청 입력 참조 문제를 보완했다.

## 검증

- pytest 전체480건 통과, 종료 오류 없음. 시스템 Temp 권한 실패 후 프로젝트 .local basetemp로 전체 재실행했다.
- Ruff 전체, mypy86파일, frontend typecheck/build 통과. Windows standalone 빌드는 권한 제한으로 동일 명령을 승인된 실행 환경에서 수행했다.
- 격리 DB 통합 테스트: 부분 저장/버전 충돌/workspace 경계/기존 voice 보존/답변 계보/WAN payload/미지원 모델.
- UI 실제1600px 밝음/어둠, 실제400px 좁은 화면: 간격16px, 데스크톱 입력 상단·높이 일치, 가로 넘침 없음. 기존 설명과 음성1개 유지 확인.
- 서버 저장 없는 임시 검증 route에서 오류409와 성공 자동 접힘/긴 문구/비활성 상태 확인. route 제거, 사용자 테마 및 viewport 복원. 증거: .local/diagnostics/voice-directions/.
- 사용자 작품·설정 저장 및 유료 외부 생성 없음. 실제 목소리 품질/클립 간 음색 일관성/터치 실기기는 미검증.
- 로컬 에이전트 워커 정상 재시작 후 running 확인. DB migration 없음. 기존 비디오 답변에는 소급 적용하지 않으며 특징 저장 뒤 다시 요청한다.
