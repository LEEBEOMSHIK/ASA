# ASA-039 연결 흐름 추적

## 구현
기존 장애물 회피 경로는 유지한다. 모든 선을 서로 다른 경로로 강제로 밀면 우회 길이와 계산량이 증가하므로, 이번 변경은 교차점 분리 표시와 개별 연결 추적을 결합했다.

SVG 선 아래 배경색 외곽선을 넣고 확대 배율과 무관한 선/클릭 영역 두께를 사용한다. 연결을 선택하면 맨 위에 표시하고 다른 선은 흐리게 한다. 출발·경로·도착 이름, 양끝 블록 강조, 검색 가능한 전체 연결 목록, 단독 보기, 해제를 제공한다. Enter/Space로 선을 선택하고 Escape로 해제한다. 선택 상태는 저장/실행 정의에 포함하지 않는다.

## 브라우저 확인
10블록12연결 검증용 초안에서 반환 연결을 키보드로 선택했다. 단독 보기 DOM 선 1개/강조 블록 2개 확인. 검색 후 다른 연결 선택과 설명 변경 확인. Escape로 선 12개 복귀 및 요약 해제 확인. 40% 축소 화면에서 선택선과 양끝 블록을 확인했다. 테스트 중 초안은 계속 저장됨 상태로 유지됐다.
