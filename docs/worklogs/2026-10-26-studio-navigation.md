# ASA-031 공통 탐색과 빌더 UI

고객 화면의 밑줄 링크로 추가됐던 자동화 진입을 공통 StudioNavigation으로 교체했다.
작업 공간/자동화 빌더/에이전트/도구 라이브러리의 이름·순서·아이콘·현재 위치를 통일했다.
새 작업은 별도 primary 행동으로 표시하고 중복된 관리자 링크는 제거했다.
RegistryShell에도 같은 사이드바와 현재 화면 경로를 적용했다. 모바일은 접이식 탐색을 제공한다.
빌더는 제목 크기·패널 간격·작업 흐름 제목·선택 강조를 정리했다. 기능/저장 데이터 변경 없음.

검증: scripts/check.ps1 — pytest43개·ruff·mypy22개 소스·frontend typecheck/build 통과.
실제 브라우저에서 고객→빌더 이동/저장 초안 선택/모바일 메뉴에서 Enter로 복귀 확인.
360px 빌더 scrollWidth=clientWidth=345 확인. 고객 모바일 dialog 열기/Escape 닫기,
밝은/어두운 테마 전환 및 데스크톱 화면 확인. 전체 스크린리더 검사는 수행하지 않았다.
디자인 시스템 문서에 공통 탐색 계약을 추가했다. AI 호출·커밋·push 없음.
