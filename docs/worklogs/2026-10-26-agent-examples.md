# ASA-016 입력·결과 예시와 도구 그룹

2번에 대본 작가·아이디어 기획자·검수자의 입력값→결과 예시를 제공한다.
고정 설명 예시임을 표시하며 전환은 현재 초안을 수정하거나 AI를 호출하지 않는다.
3번에 ASA 기본 도구와 내가 만든 에이전트를 별도 fieldset/legend로 제공한다.
선택 개수, 비어 있는 목록 안내, 미구현 및 자기 참조 불가 이유를 표시한다.
선택은 사용 권한이며 호출 순서나 필수 호출이 아님을 설명한다.

검증: 실제 DB 포함 pytest29개·ruff/mypy·웹 typecheck/build 통과.
브라우저에서 검수자 예시 전환 시 초안이 변경되지 않음을 확인했다.
기존 확인용 ‘샘플 · 쉬운 대본 작가’ 초안에서 ASA 길이 검사와 다른 샘플 에이전트를
동시에 선택·저장하고 새로고침 후 양쪽 선택이 유지됨을 확인했다. 기존 확정 버전은 변경하지 않았다.
360px에서 수평 넘침 없음. 기본 화면 예시 배치를 시각 확인했다.
빈 작업 공간은 이번 브라우저 검사에서 재현하지 않았다. 유료 호출·커밋·push 없음.
