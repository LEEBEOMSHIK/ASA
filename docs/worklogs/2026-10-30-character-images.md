# 캐릭터 설정과 기준 이미지 연결 검증

## 구현
- 캐릭터 설정 에이전트 v1: `6d009f0d-a677-48d4-956a-8572436f54f4`. 지침과 입력/답변 계약은 에이전트 편집에서 수정 가능. 재사용 템플릿 `docs/agent-templates/character-designer.json`.
- `/characters`: 기존 자동화의 각 완료 단계 선택 또는 대본/장면 원문 입력 → 등록 에이전트 실행 → 캐릭터별 설정 확인 → 이미지 생성/이전 이미지로 수정/버전 선택/명시적 확정.
- 이미지 전용 DB 큐와 로컬 워커, 같은 요청ID 멱등 접수, 같은 캐릭터 활성 작업1개, workspace 격리, 인증 이미지 응답, CSRF, 확정 포인터 비교 갱신. 워커 중단 시 불확실 호출을 재실행하지 않음.
- 이미지 모델 선택: 서버 허용 목록의 Sunburst/Flare. 이미지 도구 라이브러리에 사용법과 전용 화면 링크. 자동화 블록 직접 이미지 실행은 미지원으로 명시.
- 독립 리뷰의 요청 접수 ID 유실/늦은 폴링 응답/이전 버전 설정 복원/잘못된 답변 무한 대기 문제 보완. 접수 중 새로고침 시 같은 요청 확인 버튼 제공.

- 캐릭터 설정 요청 `c408792f-432e-4485-ba40-11b8ecd991ba`: 완료, 7개 설정(주요 인물3명 + 그림책 인물3개 + 생일 친구). 캐릭터 프로젝트 `9412edc1-6d01-4ea9-add8-fa0e83580f06`.

## 검증
- backend pytest 전체185통과(203.17초), ruff src/mypy src38파일 통과. 이미지 큐 통합: 중복접수/참조bytes 전달/버전보존/확정충돌/workspace격리/중단재시도차단.
- frontend32테스트/typecheck/build 통과. 첫 제한된 build EPERM 후 권한 허용 실행으로 성공.
- 실제 API 미인증 이미지401/CSRF 없는 확정403/로그인 후 PNG 반환/워커온라인 확인.
- Chrome에서 캐릭터 메뉴, 등록 프로젝트, 이미지 표시, v1↔v2 전환, 수정 입력과 확정 버튼 확인. 실제 기준 확정은 사용자에게 남김(확정 API는 격리DB 테스트).
- 이미지·원문·스크린샷·로컬검증 파일은 `.local/verification/character-*`에 보관하며 커밋 제외.
