# ASA-167 이전 작업 답변 가져오기

승인된 범위: 대본·장면 구성을 이전 에이전트 작업에서 선택하고 확정 캐릭터 이미지와 함께 전달한다.

구현 계획:
1. workspace 내 답변이 존재하는 작업만 검색·페이지 조회한다. 선택한 작업의 불변 답변 버전과 전체 답변/문자열 항목을 제공한다.
2. 긴 글 입력에 ‘이전 작업에서 가져오기’를 제공한다. 모달에서 출처/버전/내용을 확인 후 입력을 대체한다. 취소는 입력을 보존한다. 원본 자동 동기화나 임의 요약은 하지 않는다.
3. 자동화의 기존 앞 블록 결과 바인딩을 확인하고 대본→장면→씬 이미지 입력에 원문 및 확정 이미지 바이트가 함께 전달되는 통합 테스트를 추가한다.
4. 실제 화면, 필수 검사 후 결과를 기록한다. 사용자 자료 변경·유료 AI 생성·커밋은 하지 않는다.

## 구현 및 검증 결과
- 이전 작업 검색·페이지·답변 버전·문자열 항목 선택 API와 긴 글 입력의 가져오기 모달 구현. 읽기 전용이며 workspace 경계를 검증한다.
- 자동화 기존 앞 블록 결과 연결을 그대로 사용한다. 대본 생성 → 장면 구성 → 씬 이미지 에이전트 실행 경로에서 원문 입력과 확정 캐릭터 이미지 bytes가 함께 모델 메시지에 들어감을 통합 테스트로 확인했다.
- 전체 backend pytest 272 passed, ruff/mypy 통과. frontend typecheck/build 통과. git diff --check 통과.
- 실제 Chrome: 장면 구성 3,874자와 대본 2,519자를 각각 가져오기, 대본 미리보기와 입력값 완전 일치, 취소 시 입력 유지, 검색 결과 없음 안내 확인.
- 다크 데스크톱과 밝은 모바일 레이아웃 확인. 모바일 한 열 구성 및 대화상자 내부 가로 넘침 없음 확인. 임시 viewport와 테마 복원.
