# ASA-081 등록된 에이전트 답변 계약

- 고객 실행 큐/수동 고객 워커가 등록 버전의 지침과 output_schema를 사용한다. 고정된 짧은 대본 역할 및 title/narration 출력 강제를 제거했다.
- 신규 답변은 script_versions.answer에 원형으로 저장한다. 원래 요청과 선택한 이전 답변을 수정 요청에 전달한다. 기존 제목/대본 버전은 그대로 보존한다.
- 고객 화면은 스키마 설명을 항목명으로 사용하여 문단/목록/값을 표시하고 같은 구조로 수정한다. JSON 포장은 표시하지 않는다.
- 쉬운 대본 작가 v4 등록: 구체적인 도입, 이유 설명, 일상 예시, 마무리, 분량/근거/수정 원칙 보강. 길이 미지정에만 약60초 기본값. 답변 항목은 기존 result를 유지하고 설명을 완성된 대본으로 정리했다.
