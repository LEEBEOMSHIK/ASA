# 관리자 AI 사용량·비용과 요청 추적

`/monitoring`에서 기간, 공급자, 요청 출처, 상태와 요청 내용/모델/자동화 이름/실행 ID로 조회한다. 기간은 브라우저의 현지 날짜 기준, API는 timezone을 포함한 시작 이상·종료 미만 범위다. 최대 366일. 요약은 전체 조회 결과, 목록은 25개씩, 모델·작업 집계는 호출 수 상위 50개다.

원래 요청 → 실행 → 블록별 호출을 연결한다. 직접/예약 자동화, 고객 대본 CLI 워커, 운영자 대본 CLI가 수집 대상이다. 일반 도구·Brave 검색은 AI 토큰 수집 대상이 아니다. OpenAI/Claude 내장 검색은 해당 AI 호출의 토큰을 기록하되 검색 추가 요금은 계산하지 않는다. 기존 호출은 소급 수집하지 않는다.

## 실행 및 설정

먼저 `uv run --locked --project services/backend python -m asa.registry.init`을 실행한다. 기존 테이블은 보존하고 호출 기록 테이블과 요청자/시각 컬럼을 추가한다. 이후 API와 자동화 워커를 재시작한다. 수집을 위한 외부 서비스·외부 tracing 전송은 없다. 실제 AI 테스트에는 기존 API 키/모델 설정과 활성화가 필요하다.

`ASA_AI_PRICES`는 JSON 객체다. 키는 `openai:모델ID` 또는 `anthropic:모델ID`, 값은 다음 필드를 가진다.

| 필드 | 의미 |
|---|---|
| label | 확인한 요율의 기준일·버전 설명 (필수) |
| input, output | 일반 입력/출력 100만 토큰당 USD (필수) |
| cache_read | 캐시 읽기 100만 토큰당 USD |
| cache_creation | TTL 구분이 없는 캐시 생성 100만 토큰당 USD |
| cache_creation_5m, cache_creation_1h | 공급자가 반환한 TTL별 캐시 생성 요율 |

빈 기본값 `{}`에서는 토큰·시간·요청 추적은 동작하고 비용은 **요율 미등록**이다. 실제 요율은 운영자가 공급자·모델·서비스 등급에 맞게 확인해 입력한다. 가격을 임의의 최신 요금으로 하드코딩하지 않는다. 임의 0을 입력하면 무료로 계산되므로 모르는 가격은 미등록으로 둔다. 요율 변경 후 워커를 재시작한다. 각 호출에 당시 요율 스냅샷을 저장하므로 과거 예상 비용은 변하지 않는다. 할인/배치/장문 tier/세금/환율/검색 도구 비용은 자동 반영하지 않는다. USD 예상 금액이며 최종 청구서는 공급자를 기준으로 확인한다.

## 집계와 실패 기준

- LangChain의 공급자 반환 usage_metadata를 사용한다. Claude의 input_tokens는 어댑터에서 캐시를 포함한 합계로 변환되므로 캐시를 빼고 일반 입력 단가를 적용한다. TTL별 캐시 생성도 별도 계산한다. 필요한 캐시 요율이 없으면 비용은 미산정이다.
- 토큰이 없는 응답·연결 단절은 **사용량 미확인**이다. 0 토큰이 실제 반환된 경우와 다르다. 오류 응답의 실제 청구 여부는 추정하지 않는다.
- 응답을 받은 뒤 출력 파싱이 실패해도 확보한 사용량은 보존한다. 프로세스 강제 종료 시 시작 기록은 **완료 미확인**으로 남는다. 실행 중/중단을 구별하지 못하는 이 상태를 실패나 무료로 확정하지 않는다.
- 자동 재시도는 하지 않는다. 호출 기록 시작 저장 실패 시 외부 호출을 시작하지 않는다. 기록 저장과 외부 호출 사이의 exactly-once는 보장하지 않는다.
- 평균 시간은 모델 시작/종료·오류 callback에서 측정된 응답 시간만 집계한다. 상세의 자동화 최초 대기 시간과 마지막 상태 변경까지의 경과 시간(승인 대기 포함)은 별도다.
- 자동화 이름이 변경되어도 ID로 합산하며 최근 이름을 표시한다. 고객 대본·운영자 CLI는 출처별 작업으로 합산한다. 반복 실행 블록은 각각 별도 호출 기록이다.

## 권한과 민감 정보

API에서 owner/admin 역할과 세션 workspace를 검사한다. 클라이언트가 조회 workspace를 선택할 수 없다. 요청자 ID는 서버 세션에서 저장하며 예약은 예약 저장자의 ID를 이어받는다. 기존 요청/예약의 누락된 요청자는 미확인으로 남긴다. 현재 개인 소유자 계정은 local-owner이며 SaaS 사용자 인증이 구현된 것은 아니다.

목록 API는 원문을 반환하지 않는다. 상세에서 원래 요청, 실제 모델에 전달한 system/human 메시지, raw 응답 콘텐츠와 구조화 tool_calls를 조회한다. API 키·소유자 키·DB URL 등 설정 비밀값과 일반적인 비밀 필드명은 마스킹하고 직렬화 JSON도 처리한다. 공급자 오류 원문·HTTP 헤더는 수집하지 않는다. 전문은 필드당 64,000자, 중첩 깊이 30으로 제한한다. 이는 임의 개인정보를 모두 탐지하는 DLP 기능은 아니다. 보관 기간 자동 삭제·감사 로그·사용자별 비용 한도는 후속 범위다.

실제 UI 검증의 모의 데이터는 검증용임을 명시하고 검증 후 제거한다. 실제 유료 호출을 검증 성공으로 주장하지 않는다.


ASA-065: 요율 스냅샷에 long_context(input_tokens_gt 및 전체 구간 요율)를 포함한다. 정규화 input_tokens는 캐시 토큰을 포함하며 기준 초과 요청에는 구간 요율을 요청 전체에 적용한다. 기준 이하에는 기본 요율을 사용한다. 상위 구간의 캐시 요율이 확인되지 않았고 해당 캐시를 사용했다면 cache_rate_missing으로 비용을 미확인 처리한다. 공식 요율 조회는 모델 관리에서 수행하며 실제 생성 단위 테스트는 실행하지 않는다.

## OpenAI 공식 집계

기존 ASA 요청별 예상 비용과 별도 화면에서 OpenAI Costs API 비용과 Completions Usage API 토큰을 조회합니다. 두 비용을 합산하지 않습니다. 충전 잔액은 OpenAI 결제 화면에서 확인하며 수동 잔액 및 Codex 연동은 제공하지 않습니다.

서버 환경변수 ASA_OPENAI_ADMIN_API_KEY(별도 Admin API Key)가 필요합니다. ASA_OPENAI_USAGE_PROJECT_ID가 없으면 조직 전체, 있으면 해당 프로젝트를 조회합니다. 서버 설정 workspace의 소유자만 접근합니다. 키는 화면과 응답에 노출하지 않습니다.

비용은 UTC 오늘/이번 달/최근 7일/30일, 토큰은 화면에 명시한 조회 기간입니다. 전용 이미지·음성 사용량은 텍스트 토큰 합계에서 제외되며 Costs 금액은 전체 비용 항목을 포함합니다. 공식 집계도 공급자 반영 지연이 있을 수 있습니다.

API 프로세스별 메모리에 15분 캐시합니다. 수동 갱신 최소 간격은 30초이며 실패 후 자동 재조회 간격은 60초입니다. 페이지가 열려 있을 때 15분마다 조회합니다. 실패하면 마지막 정상 데이터와 갱신 실패를 함께 표시하고, 데이터가 없으면 미확인으로 유지합니다. 서버 재시작 시 캐시는 초기화됩니다. 백그라운드 영구 수집은 이번 범위에 포함하지 않습니다.

설정 후 API 서버를 재시작합니다. Admin API Key 미설정 환경에서는 실제 계정 비용 검증이 불가능하며, 생성용 키만으로 연결됐다고 표시하지 않습니다.
