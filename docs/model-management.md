# 관리자 모델 관리

ASA-058. 관리자 `/models`에서 공급자(OpenAI/Claude), 정확한 API 모델 ID, 표시 이름,
사용 허용, 작업 공간 기본 모델, 웹 검색 허용, 선택적 USD/100만 토큰 요율을 관리한다.
ASA-061: 모델 추가에서 공급자를 선택하면 목록을 자동 조회한다. 검색 가능한 한 개의 콤보박스로 선택한다.
이 화면을 유지하는 동안 공급자별 목록을 재사용하며 오류 시 다시 확인할 수 있다.
정렬은 모델 ID의 세대 번호 내림차순, 같은 세대의 일반 모델 우선, 날짜 고정 버전보다 별칭 우선이다.
특수 용도/알 수 없는 계열은 뒤에 표시하되 검색 가능하다. 벤치마크 성능 순위는 아니다. 서버가 공급자
Models API를 조회하고, 선택한 모델의 공식 Markdown 문서를 읽어 검색 지원과 표준 요율을
자동 입력한다. 확인 시각·출처를 저장하며 공식 정보 갱신으로 다시 확인할 수 있다.
새 모델은 선택한 모델 등록 버튼에서 즉시 DB에 저장된다. 기존 모델의 정보 갱신과 편집은 편집 내용 저장으로 적용된다.
API 키는 `.env`에 유지하고 응답에는 키 설정 여부만 제공한다. 키 변경은 서버 재시작이 필요하다.

모델 카탈로그는 workspace별 DB에 저장하며 owner/admin만 수정·조회한다. 일반 사용자에게는
활성 모델 목록만 제공한다. 낙관적 revision으로 동시 편집 충돌을 막는다.
저장된 DB 설정이 있으면 환경 변수 모델 목록보다 우선하며, 최초 저장 전에는 환경 설정을 읽는다.
관리자 설정은 API 요청 및 워커 실행 시 읽으므로 모델 목록 변경에는 재시작이 필요 없다.
`ASA_AUTOMATION_AI_ENABLED` 실행 허용과 워커 시작은 별도로 유지한다.

AI 요청 블록은 공급자·모델을 직접 선택한다. 에이전트는 초안과 발행된 불변 버전에 선택을
저장하고 자동화가 해당 버전을 연결할 때 그 모델을 사용한다. 미선택은 작업 공간 기본 모델을
따른다. 자동화 실행 manifest에 실제 선택 모델을 고정하며 비활성화된 모델은 실행을 차단한다.
기본 모델이 변경된 기존 예약/대기 실행은 기존 안전 규칙에 따라 재설정이 필요할 수 있다.
고객 대본 실행도 요청 당시 에이전트 버전의 모델을 사용한다.

비용 요율 미등록은 미확인으로 처리하고 과거 호출의 요율 스냅샷은 변경하지 않는다.
웹 검색 비용은 토큰 비용 외 별도 요금이 있을 수 있어 모니터링의 기존 부분 비용 표시를 유지한다.
캐시 읽기·쓰기(일반/5분/1시간) 요율도 자동 반영하며 고급 설정에서 수정할 수 있다.
공식 정보 갱신은 검색 허용과 요율을 덮어쓴다. 문서 실패·ID 미확인·해석하지 못한 요금 조건은
추정하지 않고 미확인으로 남긴다. 표준 텍스트 요율만 지원하며 검색 도구 요금·계약 할인은
포함하지 않는다. 공식 문서 형식 변경 시 수동 확인이 필요할 수 있다.
OpenAI 문서에 Chat Completions/structured_outputs 미지원이 확인되면 가져오기를 차단한다.
호환성 미확인은 실행 성공을 보장하지 않는다. 모델별 API 접근 권한·실행 한도는 별도다.

목록/메타데이터 API도 owner/admin 인증을 요구한다. 모델 목록 인증은 공급자 고정 URL에만
전송하고, 공식 문서에는 키를 보내지 않는다. 사용자 URL과 리다이렉트는 허용하지 않는다.
Claude 목록 페이지네이션·응답 크기 제한·오류 메시지 비밀값 제거를 적용한다.

검증: 모의 데이터로 관리자 권한·workspace 격리·중복 ID·기본 모델 유효성·충돌·에이전트 모델
발행/실행 snapshot·비활성화 차단을 검사한다. OpenAI 실제 목록 조회와 공식 문서 자동 입력을 확인했다. Claude 목록은 키 미설정으로
모의 응답 검증만 수행했다. AI 생성 호출은 수행하지 않았다.

## 목록과 요율 편집 (ASA-064)
등록 모델 목록은 검색 가능하고 최대 높이360px 내부 스크롤을 사용한다. 한 번에 한 모델의 상세만 연다. 모델을 전환해도 미저장 초안은 유지한다. 요율은 자동 확인됨/직접 수정됨/확인 필요로 구분하며 금액이 비어 있으면 등록 완료로 표시하지 않는다.
수동 편집은 기본 접힘이며 입력/출력의 단위와 용도를 설명한다. 캐시 요율은 추가 접힘 영역이다. 모델을 전환해 숨겨진 잘못된 요율도 저장 전 전체 초안 검증으로 발견하고 해당 모델을 연다. 실제 청구가 아닌 모니터링 예상 금액 기준임을 안내한다.

## 공식 요율 자동 적용 (ASA-065)
일반 화면은 읽기 전용 표준/긴 입력 요율 표를 표시한다. 비용 사용 체크박스와 기본 수동 입력은 제거했다. 별도 계약만 고급 설정에서 단일 요율로 대체하며 해제 시 마지막 공식 요율로 복원한다. 검색 허용을 사용자가 껐으면 공식 갱신이 임의로 켜지 않는다(미지원 확인 시 끈다).
ModelPrice.long_context는 input_tokens_gt와 해당 구간의 전체 요율을 저장한다. 캐시를 포함한 정규화된 input_tokens가 기준을 초과하면 요청 전체에 긴 입력 요율을 적용한다. 경계값은 표준 요율이다. 호출별 요율 스냅샷에 조건도 보존한다.
지원 형식은 OpenAI의 명시된 긴 입력 배수 문장과 Claude의 up to/over 이중 가격표다. 문서에서 긴 입력의 캐시 배수가 명시되지 않으면 해당 구간 캐시 비용은 미확인이다. 해석할 수 없는 조건은 미확인으로 유지한다. 표준 처리 기준이며 Fast/Ultrafast/Batch/Flex·지역·검색 도구·계약 할증/할인은 자동 계산 범위에 포함되지 않는다. 가격 변경은 공식 정보 갱신 후 저장해야 적용된다.

## 즉시 등록 (ASA-066)
외부 버튼 + 새 모델은 등록 패널을 열고, 내부 선택한 모델 등록은 공식 정보를 확인한 뒤 POST /admin/models로 즉시 저장한다. 성공 응답을 받은 뒤에만 목록에 추가하고 저장 완료를 표시한다. 재조회/새로고침에도 등록 모델은 유지된다. 기존 모델의 미저장 편집과 기본 모델 변경은 등록 요청에 포함하지 않으며, 등록 후 새 revision을 적용하고 편집 초안은 유지한다. 편집 취소는 저장된 목록을 다시 읽으므로 등록된 새 모델을 제거하지 않는다. owner/admin·CSRF·workspace 잠금·revision·중복/최대100개 검증을 적용한다.

ASA-067: 요율 제목 옆 요율 직접 설정 버튼에서 즉시 편집한다. 기존 표준 금액을 초깃값으로 채우고 단일 수동 요율로 전환한다. 공식 요율로 복원은 마지막 확인한 조건부 요율을 포함해 복원한다. 별도 고급 설정 접힘은 없애고 캐시 항목만 선택적으로 펼친다. 편집 내용은 저장 전 초안이며 자동으로 저장하지 않는다.
