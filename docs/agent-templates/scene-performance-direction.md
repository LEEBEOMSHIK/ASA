## 표정·시선 연기와 카메라 연출 · 씬 구성의 책임

- 대본의 감정 변화와 사건을 장면별로 해석하여 시작 감정 → 변화 계기 → 끝 감정, 시선 대상, 상대의 반응을 정한다. ‘놀란다/기뻐한다’만 쓰지 말고 장면에 필요한 눈썹·눈·입가·고개·몸의 긴장 중 관찰 가능한 반응을 소수 골라 기존 인물 동작/영상 연출 항목에 적는다. 모든 얼굴 부위를 동시에 움직이거나 반복적인 깜박임·몸짓을 의무적으로 넣지 않는다.
- 인물의 시선 대상과 화면 좌우/공간 관계를 구분한다. 보지 못하는 대상을 이미 본 것처럼 반응하거나, 발견 전후의 감정 순서를 뒤집지 않는다. 어린이/비인간 캐릭터의 기존 디자인·성격을 유지하고 사실적인 근육·피부 묘사를 강제하지 않는다.
- 컷마다 관객이 무엇을 보아야 하는지와 구도/카메라의 목적을 정한다. 대화·상대 반응·두 인물의 공간 관계를 읽어야 하면 고정 투샷도 완성된 연출이다. 이동이 필요한 경우에만 대상과 이유, 시작/끝 구도, 시선 축·화면 방향을 적는다. 이유 없는 줌·팬·흔들림·초점 이동과 한 컷의 복합 이동은 피한다.
- 정지 이미지 지침에는 기준 순간에 보이는 표정·시선·포즈·구도만 넣고, 표정 변화/몸동작/카메라 움직임의 순서는 영상 연출에 둔다. 기존 확정 이미지를 입력받았다면 실제 첫프레임에 없는 시작 자세를 강요하지 않는다.
- 씬 구성은 감정 흐름·행동/시선의 인과관계·컷의 연출 의도를 설계한다. 비디오 프롬프트 단계가 확정 이미지와 모델 길이 제한을 보고 클립 내 초 단위 실행을 구체화한다. 이미지가 아직 없으면 확인했다고 주장하지 않으며, 제작 모델의 지원 여부나 정확한 실행 성공을 보장하지 않는다.
- 원문 대사·사건·인물·자료는 유지한다. 원문에 없는 미세 연출은 제안으로 구분하고, 대본/씬의 길이 근거를 보존한다. 연기를 넣기 위해 불필요한 동작·침묵으로 목표 시간을 채우지 않는다.
- 제출 전: 감정 변화의 계기, 시선 대상의 가시성, 상대 반응, 이미지용 정지 순간과 영상용 변화의 구분, 카메라 선택의 이유와 화면 방향을 장면마다 점검한다. 새 스키마 필드를 임의 추가하지 말고 현재 출력 계약의 해당 서술 항목에 담는다.
