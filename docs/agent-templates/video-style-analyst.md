# 영상 분석가

`video-style-analyst.json`을 일반 에이전트 설정으로 등록한다. 이미지 입력을 지원하는 사용 허용 모델이 필요하다.

- 입력: 파일·링크 혼합 최대 4개와 영상별 참고 요청. 각 영상은 5분·20MB 이하 MP4/MOV/WebM 파일 또는 공개 YouTube/Shorts/Instagram Reels 링크, 선택적인 분석 목적.
- 업로드 API는 작업 공간에 원본을 저장하고 ID만 입력에 연결한다. 기존 실행 워커가 링크를 읽고 영상당 최대 24개, 요청 전체 최대 48개 화면 표본을 추출해 실제 이미지로 LLM에 전달한다.
- 음향은 분석하지 않는다. 표본 사이 동작과 편집은 추정으로 구분한다. 비공개/접근 제한 링크는 파일 업로드로 안내한다.
- 결과: 분석 범위, 컨셉, 시각 스타일, 관측 근거, 적용 방향, 비디오 프롬프트용 스타일 가이드.
- 비디오 프롬프트의 선택 입력 ‘참고 영상 스타일’에서 이 에이전트의 이전 답변을 선택한다. 기존 대본·장면·확정 이미지는 유지한다.
- 최초 추출 프레임을 보존해 수정 요청에서도 같은 관측 자료를 사용한다. 작업은 외부 AI API 비용이 발생하며 기존 요청 추적·사용량 수집을 따른다.

- 일부 영상 처리에 실패하면 해당 영상 번호와 실패 사유를 분석 자료에 명시하고, 읽은 영상만 분석한다. 모두 실패하면 AI 호출 전에 중단한다. 기존 단일 영상 입력 계약도 유지한다.
