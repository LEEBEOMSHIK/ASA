## 참조 기반 영상 · 캐릭터와 화자 일관성

- original_request.video_references가 있고 해당 clip_id가 clip_ids에 포함될 때만 reference_inputs에 그 character_image_ids와 audio를 그대로 복사한 객체 1개를 넣는다. 나머지 클립은 빈 배열이다. 사용자가 선택하지 않은 영상·이미지·음성 ID나 구간을 추측하지 않는다. reference_inputs.audio도 0개 또는 1개 배열이며 실제 음성 참조와 기존 audio_plan의 목소리 설명은 별개다.
- 참조 모드에서는 Image 1이 해당 씬 이미지, Image 2부터는 character_image_ids 순서의 캐릭터 기준이다. Audio 1은 지정 화자의 음색 기준이다. prompt에 번호와 역할을 명시하고, Audio 1의 과거 대사·배경음·효과음을 복사하지 말고 기존 audio_plan의 이번 대사와 시간을 따른다. 지정하지 않은 화자의 음색까지 같은 목소리로 바꾸지 않는다.
- 참조 모드는 첫 프레임 고정이 아니다. 씬 이미지의 공간·화풍·좌우 관계와 캐릭터 기준의 얼굴·신체 비율·형태를 유지하면서 연기에 필요한 시작 자세를 계획한다. 기존 first-frame 계획의 제약을 참조 모드에 그대로 적용하거나, 완전한 첫 프레임 일치·음색 복제 성공을 보장하지 않는다. 미선택 클립의 기존 시작 방식은 유지한다.
- 캐릭터별 유지할 외형을 실제 참조 이미지에 근거해 짧게 명시한다. 작은 둥근 유령이라면 짧은 팔·발 없는 물결형 밑단·작은 얼굴 등 식별 특징을 유지한다. 긴 팔·다리·사람 같은 체형으로 변형하지 않는다. 가려진 씬에서는 기준 이미지가 있다는 이유로 얼굴·전신을 조기 공개하지 않는다. 뒤 클립의 공개 시점과 대사 흐름을 지킨다.
- 생성된 영상에 대한 사용자 관찰이 제공되면 계획상의 종료 상태와 실제 영상의 종료 상태를 구분한다. 새 계획끼리의 연결과 기존 영상을 유지하는 경우의 연결을 각각 검토한다. 대사·음성 설정·이미지 자료를 임의 변경하지 않는다. 새 계획은 기존 영상 자체를 수정하지 않으며 영상 생성은 별도 사용자 실행이다.
- 제출 전 reference_inputs의 사용자 선택 일치, 이미지 번호/캐릭터 역할, Audio 1의 지정 화자, 원래 대사·발화 시간·음성 설정 보존, 초반 움직임과 끝 상태 연결, 유령 공개 시점·외형 유지, 정확한 구절 분류를 점검한다. 전달 주소 등 실행 설정이 미완료인 경우도 계획 품질과 구분하며 생성 가능하다고 추측하지 않는다.

- 사용자가 video_references.video를 지정했을 때만 해당 클립의 reference_inputs.video에 복사한다. Video 1은 지정 영상의 동작·외형·연결 참고이며 시작 프레임 고정이나 기존 대사·음성 설정 변경 승인이 아니다. 영상 ID·URL을 추측하지 않는다. 참조 영상 업로드와 지원 제한·요금 검증은 실행 계층이 담당한다.
