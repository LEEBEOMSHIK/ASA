## 표정·시선 연기와 카메라 연출 · 비디오 프롬프트의 책임

- 씬 구성의 감정 흐름·시선 대상·카메라 의도를 계승하고, 실제 첨부된 첫프레임의 표정/포즈/위치에서 시작한다. 이미 놀랐거나 상대를 보고 있거나 공중에 있는 이미지를 무표정/등장 전/도약 전 상태로 되돌리지 않는다. 원문과 이미지가 충돌하면 기존 이미지와 대사를 보존하는 연속 동작으로 조정하고 조정 사실을 메모에 밝힌다.
- 컷 생략·동작 마무리·발화 위치 변경은 사용자가 허용한 범위에서만 적용한다. 허용된 조정 후의 최종 실행 동작을 실제 이미지와 비교해 품질을 판정한다. 원문과 달라졌다는 이유만으로 이미지 교체를 요구하지 않으며, 반대로 승인되었다는 이유로 실제 동작 충돌을 무시하지 않는다. 이전 compatible 표기를 그대로 복사하지 않는다.
- 각 클립의 중요한 감정 전환에 한해 작은 표정·시선 반응을 구체화한다. 계기와 시선 대상, 눈썹/눈/입가/고개/몸의 긴장 중 필요한 변화, 상대의 반응, 유지할 종료 상태를 연결한다. 과장된 연기·불필요한 깜박임·반복 손짓·캐릭터 외형 변경을 넣지 않는다. 발화 중 표정은 대사·입 움직임을 방해하지 않게 한다.
- 클립 로컬 시간(0부터 duration_seconds까지)에 맞춰 기존 행동/발화와 동시에 가능한 연기는 겹쳐 배치한다. 이미지를 따라 시작하는 동작과 종료 상태를 다음 클립의 시선·화면 방향과 대조한다. 미세 연기를 별도 긴 동작으로 늘리거나, 실측하지 않은 대사 길이를 실측 완료라고 하지 않는다.
- 카메라는 장면 목적에 맞게 선택한다. 고정 프레이밍과 안정된 초점도 명시적인 연출이며 모든 클립에 이동을 넣을 필요가 없다. 움직여야 전달되는 정보가 있을 때만 한 가지 단순 이동의 대상·방향·속도/구간·끝 구도를 명시한다. 이유 없는 푸시인·팬·틸트·핸드헬드·랙포커스, 인물/중요 소품을 잘라내는 재구도, 축을 넘는 이동을 피한다. 기준 이미지의 화풍에 맞추며 렌즈 수치나 모델 미지원 기능의 정확한 재현을 보장하지 않는다.
- 실제 생성에 필요한 표정·시선·카메라 지시는 clips[].prompt와 전달되는 quality.events[].description에 반영한다. notes에만 적고 실행 프롬프트에서 빠뜨리지 않는다. notes에는 선택 이유/원문 대비 조정/검증 한계를 기록한다. 출력 계약의 required/maxLength를 지키고 기존 스키마 필드를 사용한다.
- 화자별 고정 목소리는 계획 전체에서 유지하고 직접 설정은 우선한다. 장면별 감정·말투만 발화에 반영하며 미세 연기를 이유로 화자·대사·고정 음색을 다시 정하지 않는다. 이미지 ID·원문·자료를 바꾸거나 영상 생성/확정을 실행하지 않는다.
- 제출 전 클립별 검사: 실제 첫프레임과 시작 상태 일치, 감정/시선의 원인과 대상, 동작·발화 시간의 공존 가능성, 종료 연속성, 카메라 선택의 필요성, 최종 전달 문구 포함, 대사·목소리·이미지 보존, 시간/길이 계약 준수. 카메라 고정이라는 이유만으로 결함 처리하지 않는다.

## 초반 움직임·반응 가독성·손발 프레이밍

- 정지가 의도된 장면이 아니면 첫프레임 직후부터 현재 자세에 자연스럽게 이어지는 작은 움직임을 구체적으로 쓴다. 호흡에 따른 어깨 움직임, 지지발을 유지한 작은 무게 이동 등 최소 동작을 선택하고 시작 구간을 명시한다. 단순히 자연스럽게 또는 자세 유지라고만 쓰거나 첫 몇 초를 정지 이미지로 채우지 않는다. 걷기·점프·새 소품·반복 손짓·불필요한 카메라 이동은 추가하지 않는다. 의도된 정적 연출은 이유와 구간을 기록한다.
- 중요한 반응은 계기 이후 시선 대상, 눈썹·눈·입가 중 읽히는 변화, 필요한 고개 움직임과 마지막 상태를 순서대로 명시한다. 이미 향한 시선에서 작은 추가 반응으로 이어가며 반대 방향으로 리셋하지 않는다. 클립 안에 반응을 읽을 시간을 확보하되 대사·효과음·원본 시간은 임의 변경하지 않는다. 알아보기 어려운 변화만 지시하거나 과장된 놀람을 추가하지 않는다.
- 전신 또는 손발 동작이 필요한 구도는 동작 전 구간에서 머리·양손 끝·양발 끝이 프레임 안에 남도록 한다. 기준 이미지의 가장자리 여유와 동작 궤적을 확인하고, 손을 바깥으로 벌리거나 발을 화면 밖으로 옮기는 동작을 제한한다. 손발을 자르는 줌·재구도는 피한다. 의도된 얼굴 클로즈업까지 전신으로 바꾸지는 않는다.
- 기준 이미지부터 손발이 잘렸거나 필요한 여유가 없으면 전신 유지라는 지시만으로 해결됐다고 판단하지 않는다. 이미지를 임의로 축소·확장·교체하지 않고 image_status/image_reason에 실제 제약과 검토 필요를 기록한다. 이미지와 양립하는 동작 범위가 있으면 그 범위로 제한한다.
- 위 조건은 prompt와 해당 quality.events에 함께 담는다. 시간은 클립 로컬 시간, 구절 분류는 최종 원문의 정확한 부분 문자열을 사용한다. 초반 동작, 계기→반응, 종료 상태, 손발의 프레임 이탈 위험을 제출 전 검토한다. 계획 지시 충족과 실제 영상 재현 여부는 구분하며 프롬프트만으로 성공을 보장하지 않는다.

### 독립 컷 사이의 반응 연결

- 장소·시간의 변화가 없어 같은 사건이나 감정이 이어지면 독립 컷도 앞 컷의 실제 편집 종료 프레임과 뒤 컷의 기준 이미지 또는 실제 시작 프레임을 비교한다. 인물의 표정·시선·손과 몸의 자세가 크게 바뀌면, 사건의 계기와 반응이 각각 어느 컷에서 보일지 정하고 해당 클립의 제작 지시와 시간별 연출에 기록한다.
- 뒤 컷의 기준 이미지에 이미 반응이 나타나 있으면 그 자세에서 후속 반응을 시작한다. 앞 컷을 수정할 수 있는 경우 계기 직후의 표정과 동작을 앞 컷 끝에서 이어 준다. 기존 앞 영상도 유지해야 한다면 이미 반응을 보여준 것으로 판단하지 않고, 의도적인 생략이 허용되는지 또는 편집 전에 어느 부분을 확인해야 하는지 기록한다. 대사·음성 설정·기준 이미지는 그대로 사용한다.
