# 비디오 프롬프트 에이전트 · 초기 구성

`video-prompt-planner.json`은 공급자와 영상 모델을 고정하지 않는 이미지를 참조하는 영상 지침 에이전트 템플릿이다. 작업 공간 기본 AI 모델을 사용하며 사용자가 설정 화면에서 모델과 지침을 변경할 수 있다.

## 입력과 출처

- 대본 전체: 대본 작가의 이전 답변 원문.
- 장면 구성: 장면 구성 에이전트의 이전 답변 원문.
- 확정 씬 이미지: 썸네일로 최대 32장을 선택한다. 실제 이미지 파일, 장면/컷 번호, 생성 당시 최종 설정과 캐릭터 설정을 함께 전달한다.
- 추가 영상 연출 요청: 사용자가 원하는 움직임·카메라·분위기 등. 선택 사항.

로컬 등록에서는 입력 항목의 `x-previous-answer` 및 `x-answer-agent`로 출처를 연결한다. 실행 사용자가 해당 출처의 이전 작업을 선택한다. 템플릿에는 환경별 에이전트 UUID를 넣지 않으며 다른 작업 공간에 등록할 때 출처를 다시 설정해야 한다.

## 답변과 확정

원본 장면 순서와 대본을 보존하고 씬마다 시작 상태, 움직임, 카메라, 종료 상태, 연속성, 음성 계획과 복사 가능한 영상 프롬프트를 작성한다. 원문에 없는 연출은 AI 제안으로 구분한다. 텍스트 답변에는 사용자 확정 설정을 적용한다. 자동 영상 생성이나 이미지 재생성은 하지 않는다.

## 이미지 전달과 검증

`asa_scene_selection_v1`은 서버가 생성한 확정 이미지 스냅샷이다. 실행 시 workspace, 확정 상태, 이미지 버전과 메타데이터를 재검증하며 변경되었으면 다시 선택해야 한다. 실제 이미지 바이트는 서버에서 모델 메시지에 첨부한다. 이미지 입력을 지원하는 모델이 필요하며 이미지 입력 비용이 발생할 수 있다.

캐릭터 설정은 이미지 생성 당시 기록을 가져온다. 별도의 캐릭터 기준 이미지를 다시 첨부하지 않는다. reference_only는 소품·형태 참고이며 등장인물로 추가하지 않는다. 대본과 장면 원문은 그대로 유지한다. 선택하지 않은 장면은 이미지 대조 대상이 아니므로 AI가 누락 여부를 안내한다.

이 기능은 비디오 프롬프트 작성까지이며 실제 영상 생성 API는 호출하지 않는다. 기존 실행 기록은 당시 입력을 유지한다.
