# 비디오 프롬프트 에이전트 · 초기 구성

`video-prompt-planner.json`은 공급자와 영상 모델을 고정하지 않는 텍스트 기반 영상 지침 에이전트 템플릿이다. 작업 공간 기본 AI 모델을 사용하며 사용자가 설정 화면에서 모델과 지침을 변경할 수 있다.

## 입력과 출처

- 대본 전체: 대본 작가의 이전 답변 원문.
- 장면 구성: 장면 구성 에이전트의 이전 답변 원문.
- 씬 이미지 제작 계획: 씬 이미지 에이전트의 이전 텍스트 답변. 선택 사항이며 실제 이미지 첨부가 아니다.
- 추가 영상 연출 요청: 사용자가 원하는 움직임·카메라·분위기 등. 선택 사항.

로컬 등록에서는 입력 항목의 `x-previous-answer` 및 `x-answer-agent`로 출처를 연결한다. 실행 사용자가 해당 출처의 이전 작업을 선택한다. 템플릿에는 환경별 에이전트 UUID를 넣지 않으며 다른 작업 공간에 등록할 때 출처를 다시 설정해야 한다.

## 답변과 확정

원본 장면 순서와 대본을 보존하고 씬마다 시작 상태, 움직임, 카메라, 종료 상태, 연속성, 음성 계획과 복사 가능한 영상 프롬프트를 작성한다. 원문에 없는 연출은 AI 제안으로 구분한다. 텍스트 답변에는 사용자 확정 설정을 적용한다. 자동 영상 생성이나 이미지 재생성은 하지 않는다.

## 아직 연결하지 않은 부분

확정 씬 이미지 파일의 선택·전달과 실제 영상 생성 API는 별도 구현이 필요하다. 현재 캐릭터 보관함 전달 형식은 씬 이미지 전달 형식으로 재사용하지 않는다. 이미지 ID나 제작 계획 텍스트만으로 이미지를 확인했다고 말하지 않도록 지침에 명시했다. 따라서 현재 결과는 확정 씬 이미지 대조 전 초안이며, 영상 생성 준비 완료를 뜻하지 않는다.

추후 씬 이미지 연결 시 workspace·실제 확정 버전·파일 접근을 검증하고 씬 ID와 이미지의 대응을 보존해야 한다. 현재 이미지 첨부 경로의 12장 제한도 전체 씬 개수와 함께 고려해야 한다. 대본과 장면 원문은 변경하지 않는다.
